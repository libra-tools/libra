## 文檔職責

本文解決 monoengine `plan-20260911.md` **DEFER-AC-01**：Libra 本機已有兩套 Agent 記錄（外部 hook 捕獲與 `libra code` JSONL），但**沒有**消費 storage-only `/api/v1/agent-capture` 的 HTTP 客戶端。目標是交付唯一公開命令 **`libra agent capture-push`**：把**外部捕獲**（`session_kind=external_capture`）的 **raw** 會話以獨立 ingest token 上傳到已 pin 的 Mega HTTP 面；不把 `refs/libra/traces` 當遠端協議，也不重放 Git push。

本文只規劃任務。落地時每張卡必須先按 ER-02 / ER-CAP-02 重核源碼錨點與 pin revision。

### 適用範圍

- 新增且僅新增 `libra agent capture-push`（既有 `libra agent push` 的 Git `traces:refs/libra/traces` 語義不變）。
- 消費已 pin、**已掛載**的 HTTP：discovery、session PUT、session-scoped blob staging/finalize、`events:batch`、`checkpoints`。
- 從本機 `agent_session` / `agent_checkpoint` 與 ObservedAgent `resolve_transcript_source` **重讀**提供者 raw 檔，計算 `event_uid = {generation}:{byte_offset}`。
- CLI 註冊、`MutationClass::ExternalOrUnknown`、穩定錯誤碼、EN/zh-CN/網站命令文件、COMPATIBILITY、測試與每卡發布。

### 非目標

- **不改** `libra agent push`、不把 traces ref 推到 Mega、不重放 `refs/libra/traces` 當 ingest。
- **不發明** HTTP 路徑或欄位；pin 上沒有的表面一律 fail-closed 或 `DEFER-*`。
- **不實作** `file-ops:batch`（本倉無 `agent.file_op.v1`；禁止從 ToolUse JSON 推斷）。
- **不宣稱** `internal_code` 可完整落地：server `bind_stream_snapshot` **沒有**公開 HTTP，GET transcript 對該 kind 會 409 `missing_raw`。本計劃拒絕上傳 Code JSONL 當完整 capture。
- **不預設**上傳 FileHistory 每檔 50 版全文（對齊 monoengine DEFER-AC-02）。
- **不新增** SQLite / 全域配置 schema（無 GC-13 writer）。
- **不讀** `LIBRA_MEGA2_TOKEN`、git `push_tokens`、OS keyring（本計劃）；不把 token 寫進 repo/global config。
- **不實作** list/show/transcript GET 操作員查詢面（discovery 除外）。
- **不提供** `--all` 批次上傳。
- **不在**本倉修改 monoengine。

### 成功定義

- 持有有效 ingest token 的開發者可對單一 `--session` 執行 `libra agent capture-push --server … --repo … --allow-raw`，在 mock 與契約測試中走過 discovery → PUT → raw staging/finalize → events:batch → checkpoint，且成功 JSON 含 `capture_id`。
- 無 `--allow-raw`、無 raw 來源、401/404/409/413、未掛載 discovery、Code session、或會 POST `file-ops` 的路徑一律 fail-closed。
- `libra agent push` 行為與測試不被本計劃改寫。
- 所有非延後卡 `Lifecycle=done` 且 `Acceptance=complete`；最新一輪 Codex 與 Claude 對本文件為字面 `VERDICT: PASS`（含 P2/P3 關閉）。

## 已決議設計決策

實現時若需偏離，必須先改本節，不得在代碼裡默改語義。

### ADR-CAP-01: 公開命令是 `capture-push`，不是改寫 `agent push`

- **Status:** Accepted
- **Context:** DEFER-AC-01 文字寫「libra `agent push` Mega remote 客戶端」。現有 `agent push` 已是 Git `refs/libra/traces` 契約（含 prune 後 `--force-rewrite` lease）。把 HTTP ingest 疊上去會變成兩個恢復軸。
- **Decision:** 新增 `libra agent capture-push`。`agent push` 的 Args、help、測試與 traces refspec **零行為變更**。help/docs 必須用對照表說明：Git traces ≠ Mega capture。
- **Alternatives considered:** 給 `agent push` 加 `--http`（拒絕：雙軸）；放在 `mega2` 下（拒絕：60912 規定唯一子命令是 `browser`，且捕獲目錄屬於 `agent`）。
- **Consequences:** 兩個命令並存。自動化必須改呼叫新動詞。
- **Revisit when:** 若 traces Git remotes 被淘汰。

### ADR-CAP-02: 只消費已掛載路徑；禁止第三套欄位

- **Status:** Accepted
- **Decision:** 客戶端只呼叫下表。路徑由外層 `/api/v1` + 內層 `/agent-capture` 組成，**不得**再疊一層 `/api/v1`。成功只接受 **HTTP 200** + 對應 JSON（transcript GET 不在範圍）。`Idempotency-Key` **不送**（server 不讀；送了也不得當冪等證據）。未知 JSON 欄位不出現在 request。client `object_key` 在 finalize **省略**。

| Method | Public path | 請求 | 成功 200 |
|---|---|---|---|
| GET | `/api/v1/agent-capture/discovery` | 無 body | `{raw_accepted:true}`；`raw_accepted!=true` fail-closed |
| PUT | `/api/v1/agent-capture/repos/{repo}/sessions/{client_session_id}` | `{session_kind,started_at?,ended_at?}` | `{capture_id:i64}` |
| POST | `/api/v1/agent-capture/sessions/{capture_id}/blobs/staging` | raw octets | `{lease_id}` 非空 |
| POST | `/api/v1/agent-capture/sessions/{capture_id}/blobs/{lease_id}/finalize` | `{digest,size?}`（無 `object_key`） | `{digest,object_key}`；`object_key` 只作回執 |
| POST | `/api/v1/agent-capture/sessions/{capture_id}/events:batch` | `{batch_id,events[{event_uid,event_kind,native_id?,lifecycle_seq?,payload}],completeness?}` | `{accepted:true}` |
| POST | `/api/v1/agent-capture/sessions/{capture_id}/checkpoints` | `{checkpoint_id,transcript_digest?,redacted_digest?,metadata?}` | `{accepted,completeness,partial_reason?}` |

`{repo}`：本機先把使用者路徑正規化成以 `/` 開頭、無 `..` / NUL / `\` 的 TEXT，再 **percent-encode 整個字串（含前導 `/`）** 成為單一 URL segment。`client_session_id` 同樣 percent-encode。

錯誤信封只解析 `error.code` / `error.message`；缺欄或非物件 fail-closed。映射：401 `unauthorized` → `LBR-AGENT-041`；404 `not_found` 或未掛載裸 404 → `LBR-AGENT-043`；409 `conflict` → `LBR-AGENT-044`；400/413 → `LBR-AGENT-045`。判定順序跟隨 server：先認證後資源。

- **Alternatives considered:** 發明 `/stream-blob` bind（拒絕：無路由）；把 list/transcript 做進 MVP（拒絕：另一軸，DEFER-CAP-03）。
- **Revisit when:** server 增加 versioned OpenAPI 或 bind HTTP。

### ADR-CAP-03: ingest token 與 mega2 / git push 憑證隔離

- **Status:** Accepted
- **Decision:** 單一 token 來源優先序：`--token-file <path>` → 環境變數 **`LIBRA_AGENT_CAPTURE_TOKEN`** → `--token`（help 必須警告 shell history）。**禁止**讀取 `LIBRA_MEGA2_TOKEN`、git credential helper、`push_tokens`、repo/global config。每個 HTTP 請求（含 discovery）帶 `Authorization: Bearer <token>`。URL 禁止 userinfo / query / fragment。base URL 必須是 HTTPS，或無 userinfo 的 loopback HTTP。`reqwest`：無 proxy、無 redirect、固定 connect/request/body 上限。token 進入 header 後立即從 argv 副本與錯誤字串 redaction。日誌/JSON/trace 不得回顯 token、Bearer 或 raw prompt。
- **Alternatives considered:** 復用 `LIBRA_MEGA2_TOKEN`（拒絕：不同 audience；push token 覆蓋 git 路徑，ingest token 覆蓋 capture repo）；匿名 discovery（拒絕：server 要 Bearer）。
- **Consequences:** 運維要單獨配置 ingest token。`push_auth=none` 不能讓本命令成功。
- **Revisit when:** 統一 versioned API credential。

### ADR-CAP-04: raw 必須是提供者原文；redacted 不得冒充 raw

- **Status:** Accepted
- **Context:** Server discovery `raw_accepted=true`；僅 redacted → `completeness=incomplete` / `missing_raw`。本機 traces 只存 redacted。
- **Decision:** 上傳前經 ObservedAgent `resolve_transcript_source` **重讀**提供者檔（與 hook 同一縫）。該 bytes 才是 staging body 與 `transcript_digest` 的輸入。`--allow-raw` **必填**（與 `checkpoint export --raw` 相同授權軸）；缺省 → `LBR-AGENT-013`，且寫 `agent_audit_log` granted=0。重讀失敗或空 → `LBR-AGENT-042`，**不**回退 traces redacted blob。**本計劃不上傳 redacted、不送 `redacted_digest`：** pin 上 finalize 把 committed key 與 `visibility` **硬編碼**為 `raw`（`agent_capture_service.rs:355`；`agent_capture_storage.rs:1411`），沒有 client visibility 參數。再 POST 一次「redacted」仍會落入 `…/raw/sha256/…`，違反本 ADR。見 DEFER-CAP-09。
- **Alternatives considered:** 上傳 traces redacted 當 raw（拒絕：污染事實源）；跳過 `--allow-raw`（拒絕：與 013 契約衝突）；另走一次 staging 填 `redacted_digest`（拒絕：同一 raw CAS）。
- **Consequences:** 提供者檔被刪的舊 session 無法發布。checkpoint 只有 raw digest。
- **Revisit when:** 本機開始耐久保存 raw；或 server 掛上 `visibility=redacted` 的 finalize 參數（DEFER-CAP-09）。

### ADR-CAP-05: `event_uid` 對齊**已上傳 raw bytes**

- **Status:** Accepted
- **Decision:** `generation` 本計劃固定 `0`（單一 raw 快照）。`byte_offset` = 該行第一個 byte 在 **同一塊 uploaded raw** 裡的偏移（含 UTF-8）。兩段都是 **非負 `i64`**（與 server `parse_event_uid` 一致：ASCII 十進制，`parse::<i64>()` 溢出即非法；禁止正負號與前導空白）。只把能 `serde_json::Value` 解析的行做成 event；非 JSON 行仍占用偏移但不發 event。`event_kind` = JSON 的 `type` 字串，缺省則 `"unknown"`（server 本就會把未知 kind 存 `unknown`）。`native_id` = `uuid` 或 `id`（有則送）。`lifecycle_seq` = 本 generation 內已解析 event 的 0-based 序。`payload` = 該行 JSON Value，不包額外 wrapper。`batch_id` = `events:0:{first_off}:{last_off}:{sha256_hex(canonical_batch)}` 的穩定字串。每批 ≤500。單 event 是否超限以 **server 同形的五鍵信封**量：`serde_json::to_vec` of `{event_uid,event_kind,native_id,lifecycle_seq,payload}`（`agent_capture_router.rs:932-944`），不是 raw 行長；該信封 >1048576 → 整次發布失敗（不截斷）。最後一批才送 `completeness=complete`，先前送 `incomplete`。客戶端**不**送 `stream_kind`（server 硬編碼 `"jsonl"`）。
- **Alternatives considered:** 用 SQLite sequence / lifecycle.jsonl 偏移（拒絕：與 raw digest 不對齊）；自動升 generation（拒絕：ADR-CAP-06）。
- **Consequences:** 同一 `client_session_id` 在 raw 改寫後再推會 409。
- **Revisit when:** 需要多 generation 重寫協議。

### ADR-CAP-06: 409 不暗升 generation、不加本地 cursor 表

- **Status:** Accepted
- **Decision:** 不新增 SQLite 表，不把 `capture_id` 寫進 `metadata_json`。重跑依賴 server 自然鍵 / receipt 冪等。HTTP 409 → `LBR-AGENT-044`，**依 receipt/path 區分訊息**，禁止一律說 tombstone：
  - PUT：`started_at`/`ended_at` 與首次成功不一致（fingerprint `:676-685`）→「session timestamps changed; PUT fingerprint is immutable」
  - events/checkpoint：fingerprint 衝突 →「payload changed for the same uid/checkpoint_id; do not bump generation」
  - tombstone（server 先於寫）→「capture is tombstoned」
  禁止為了重試改 payload 或升 generation。
- **Alternatives considered:** 本地 cursor 表（拒絕：GC-13 新軸）；409 時 generation+=1（拒絕：與仍在的 generation 0 blob 錯位）。
- **Revisit when:** 需要可恢復增量同步。

### ADR-CAP-07: 本計劃只發布 `external_capture`

- **Status:** Accepted
- **Decision:** `client_session_id` = `agent_session.session_id`。`session_kind` **一律** `external_capture`。只發布 `state=stopped` **且** `stopped_at IS NOT NULL` 的列；live / `stopped_at` 空 → `LBR-AGENT-042`，不 PUT（避免先發 live `ended_at=null`、停止後再帶 timestamp 而永久 409）。`started_at` / `ended_at` 由 `started_at` / `stopped_at` unix seconds 轉 `DateTime<Utc>`。重跑必須送**同一**對 timestamp；catalog 的 `stopped_at` 若已變（resume 再停）→ 044，訊息見 ADR-CAP-06。若 `--session` 指向 `.libra/sessions/` Code id 或不在 `agent_session` → `LBR-AGENT-042`。checkpoint：每個要發布的本機 `agent_checkpoint` 一筆 POST，`checkpoint_id` 用本機 PK，`transcript_digest` 必為該 session 已 finalize 的 raw digest；**省略** `redacted_digest`。不對 `internal_code` 發 checkpoint。
- **Alternatives considered:** 同時做 Code JSONL（拒絕：無 bind HTTP，DEFER-CAP-04）。
- **Consequences:** Code UI 會話不在本命令範圍。
- **Revisit when:** server 掛上 stream-blob bind 路徑並有 pin。

### ADR-CAP-08: 契約測試用可注入 transport，不新增 mock crate

- **Status:** Accepted
- **Decision:** `CaptureTransport` trait（`send(method, path, headers, body_bytes)`）是單一 HTTP 出口。生產用 `reqwest`。單元/集成用記憶體 fake（錄製請求、回放狀態/JSON）。**不加** httpmock/wiremock/mockito crate。禁止為測契約去打真實 Mega。
- **Alternatives considered:** 新 dev-dependency（拒絕：T-1 與供應鏈）；testcontainers（拒絕：過重）。
- **Consequences:** CLI 測試走 fake + 少量 `command_test`。
- **Revisit when:** 全倉已有共享 HTTP mock。
