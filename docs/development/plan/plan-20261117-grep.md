## 文档职责

本文解决 `libra grep`（含共享模式编译器 `src/utils/grep_pattern.rs` 与属性模块 `src/utils/attributes.rs`）在 Git 兼容测试中的 19 项已知缺陷，目标是逐卡交付可独立验收、可独立发布、附带单元/集成测试与中英文/网站文档同步的修复切片。

本文只规划任务，不宣称实现完成。落地时每个任务都必须先刷新源码锚点，再按任务卡验收。

### 适用范围

- `libra grep` 位置 `<rev>` 与 `<pathspec>` 消歧（`grep.rs` 专用消歧，不修改 `log.rs`）、CLI 参数（`-O`/`--open-files-in-pager`、`--recursive`/`--no-recursive`、负值 `--max-count`、重复 `--not`、`-h`/`--no-filename`）。
- 搜索范围、二进制/属性检测与输出渲染（排除 intent-to-add、缺失工作区条目静默、`<rev>:` 前缀、`--column` 字节列号、`--color` 与 `color.grep.*`、`-A` 与 `--max-count` 上下文窗口、`--no-index` 越界校验与树内带引号路径输出）。

- 对应测试（`tests/command/grep_test.rs`，编译在 `--test command_test`）、命令/开发/网站文档（`/Volumes/Sea/libra-backend/apps/tanstack-app/content/docs/commands/grep.en.md`）、`COMPATIBILITY.md` 与 `docs/error-codes.md`。

## 已决议设计决策

### ADR-GR-01: `grep.rs` 专用位置消歧与 `grep_pattern.rs` 方言编译器

- **Status:** Accepted
- **Context:** `#922`/`#925`/`#929`/`#932` 需要标准 `<rev> [-- <pathspec>...]` 消歧，`#930`/`#931` 需要 POSIX BRE 与括号字符类规则。
- **Decision:** `GR-00` 在 `src/command/grep.rs` 实现独立可复用的 `<rev>... [-- <pathspec>...]` 位置消歧与 `<rev>:` 输出前缀（避免与 `format-patch` 在 `src/command/log.rs` 的写集冲突）；`GR-14`/`GR-15` 在 `src/utils/grep_pattern.rs` 修复 BRE 与括号内 `\d`/`\w` 处理。
- **Alternatives considered:** 强行修改 `log.rs` 私有消歧逻辑。拒绝理由：`log.rs` 含范围 `A..B` 专用语义且与 `format-patch` 计划存在写集冲突。
- **Consequences:** 修改共享 helper 命中 ER-13 `T-1`，对应卡执行 C 组时跑双环境完整 nextest。
- **Revisit when:** 若后续抽取独立 pathspec-rev crate 时再迁移。

### ADR-GR-02: `grep.rs` 单文件写集串行化推进

- **Status:** Accepted
- **Context:** 28 张实现卡均修改 `src/command/grep.rs` 与 `tests/command/grep_test.rs`。
