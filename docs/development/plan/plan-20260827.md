> 用户裁决: TA-03 的 12 小时级度量/抗剥落门族**豁免**（ADR-NP-03；本计划以 nextest 原生廉价门等价替代；已采得的 1 次有效基线样本以本文登记常量续用）

## 文档职责

把全量测试从「单进程内锁串行」迁移到「**每测一进程 + 每测一目录**」的执行模型：cargo-nextest 默认一测一进程，进程级全局状态（cwd / env / hash_kind）随进程隔离**天然消解**，互斥只剩进程外部资源（真实云端、共享磁盘故障注入面），由注册表机械生成的 nextest 互斥组承载。每测一目录已是既有事实（全部用例 `tempfile::tempdir()` 隔离 + spawn 型用例每测独立 HOME/XDG），本计划只做验证与守卫，不做用例改写。

前置事实：`plan-20260825.md` TA-01（fail-closed 分类器，38 轮 Codex PASS）、TA-02（内容锚站点键）、TA-04（端口卫生）已提交；TA-03 的机械转换已在工作树完成且功能门全绿，其 12 小时级验证经济学被用户豁免——NP-00 以功能门口径落地该转换，作为互斥组生成的登记基座。

本文只规划任务，不宣称实现完成。落地时每个任务都必须先刷新源码锚点，再按任务卡验收。

### 非目标

- 不改任何用例的断言、名称与语义；不动 `tests/harness/**` 结构（继承 GC-PS-05）。
- 不改 `src/**`（含 `src/utils/test.rs` 的 `CWD_LOCK`——一测一进程下自然退化为单进程内部细节）。
- 不删除 `#[serial(...)]` 具名属性——注册表与互斥组生成的登记语义源，运行时惰性零成本。
- 不在本计划内变更 `CLAUDE.md`「Quality Acceptance Criteria」三门的**权威口径**——`source .env.test && cargo test --all` 仍是完成契约；nextest 是**附加**执行面。权威口径若要迁移到 nextest，须按模板 ER-04 的同批同步规则（`CLAUDE.md` + `AGENTS.md` + 采用现行模板的计划）另行立卡，本计划登记为 `DEFER-NP-04`。
- 不做 fixture 磁盘模板缓存（`DEFER-NP-01`）；不做 cwd 显式路径重构（`DEFER-PS-06` 继承兜底）；不做进程内直调（`DEFER-NP-03`）。
- 不动 `plan-20260825.md` 的 TA-05 与 PS-* 卡。

- 转换落地：`tests/**` 零无 key `#[serial]` 常驻守卫全绿；用例具名集合守恒（唯一新增 = 守卫自身交付的不变量用例，已登记）。

- 实测提速：nextest 全量单次墙钟 ≤ **0.5×** 基线常量（5921 s → ≤ 2960 s）为硬门；工程预期 15–25 min。

- 所有非延后任务 `Lifecycle=done` 且 `Acceptance` 达到收口态；完成判据全绿（含模板三门全量收口）。

## 已决议设计决策

- **ADR-NP-01（互斥组的唯一来源；2026-08-28 执行期修订）**：`.config/nextest.toml` 的 test-groups 一律由 `tests/SERIAL_REGISTRY.tsv` 机械生成，禁止手写成员；生成器与 drift 守卫随卡交付。**组形态 = 外部键并集单组 `external`**（成员 = lane 键集含任一外部键——`cloud_live`、`workspace_failpoints`——的 fn 行，加纯 `global` 站点行的宿主 target 整 target；`max-threads = 1`）。修订依据：nextest 的 test-group 是**排他成员制**（每个测试仅归属首个匹配 override 的组），复合行「入两组」不可表达，按原两组写法 197 条复合行的 `workspace_failpoints` 互斥会被静默丢弃；并集单组的互斥强度 ≥ 原两组语义，唯一代价是纯 `cloud_live`（10）与纯 `workspace_failpoints`（1）之间的无害额外串行。外部性判据 = **补集派生**：进程内闭集 {cwd, env, hash_kind}（分类器进程模型定义）之外的任何具名键都视为外部——新键默认外部、自动并入 `external`（fail-safe 方向，至多多串行）；生成器/守卫/overlap 取证三处同一规则，守卫含合成回归（`lane:some_future_service+cwd` 必须入组）。cwd/env/hash_kind 不生成组。
- **ADR-NP-02（运行器双轨窗口）**：CI 切换后保留一步回退——`base.yml` 注释保留原命令行，回退 = revert 单提交；本地 `cargo test` 始终可用（属性仍在，单进程语义不回退）。
- **ADR-NP-03（豁免的边界）**：被豁免的是 TA-03 的 3+3 采样度量门与 5 连跑/极端线程门族；**不豁免**功能正确性门（冻结/幂等/none==0/守恒/守卫/focused）。基线以 5921 s 登记常量续用（原始样本文件随机器重启丢失，方法已档）。依据：用户 2026-08-27 裁决。
- **ADR-NP-04（权威测试口径不随卡漂移）**：`CLAUDE.md` 三门中的 `cargo test --all` 在本计划全程保持权威完成契约；nextest 为附加执行面。口径迁移须按模板 ER-04 同批同步规则另行立卡（`DEFER-NP-04`）。
