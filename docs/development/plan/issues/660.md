## 已决议设计决策

### ADR-RS-01: stat 断言与平台真实值精确比对

- **Status:** Accepted
- **Context:** `dev`/`ino` 在部分文件系统或网络挂载上可合法为 0；「非零」断言不可移植。
- **Decision:** 测试以同一路径的 `stat`（Rust `std::fs::metadata` / `symlink_metadata`）读到的字段逐项与 `ls-files --debug` 输出比对；只断言「相等」，不断言「非零」。
- **Alternatives considered:** 只断言 `diff-files` 为空（漏掉字段错写）；断言非零（跨平台 flaky）。
- **Consequences:** 断言需要平台无关的读取 helper；symlink 用 `symlink_metadata`。
- **Revisit when:** 引入跨平台 stat 抽象。

### ADR-RS-02: 复用 `refresh_unchanged_tracked`

- **Status:** Accepted
- **Context:** `refresh.rs:125-131` 已实现「读真实 stat 并写回索引」，`reset` 缺调用。
- **Decision:** `reset` 各模式物化后按其受影响路径调用同一入口（或从中抽取 `pub(crate)` helper）；symlink 条目通过 entry mode 判定使用 `symlink_metadata`。
- **Alternatives considered:** reset 内联 stat + 手写 index entry（重复语义）。
- **Consequences:** 改 helper 会同时影响 add 与 reset → 命中 T-1（GC-02 共享 helper），需全量门。
- **Revisit when:** 索引层提供统一「重算 stat」API。

### ADR-RS-03: 与 #536 RS-06 的边界

- **Status:** Accepted
- **Context:** RS-06 将引入 `reset --refresh/--no-refresh`；本卡只负责 stat 事实。
- **Decision:** 本卡不新增选项；把「reset 总是刷新 stat」交给 RS-06 的 `--no-refresh` 抑制。I660-02 的验收不依赖 RS-06；若 RS-06 先落地，则本卡在其选项之上补齐 stat 断言。
- **Alternatives considered:** 本卡实现 `--no-refresh`（与 RS-06 重复且违反单一轴）。
- **Consequences:** 顺序由 DEP 决定，两种顺序都成立。
- **Revisit when:** RS-06 改变选项语义。
