## 文档职责

### 适用范围

同名 unborn orphan 上的 `libra checkout -f --orphan <same>`、`libra checkout --orphan <same>`：同名守卫放行、索引原子清空、HEAD 保持 unborn、工作树文件保留；以及 `switch --orphan <same>` 与「已提交同名分支」的拒绝边界、普通新名称 orphan 保留 start-point index 的既有契约。

### 非目标

从普通分支创建 orphan 的其它上游差异（`DEFER-I671-01`）。`switch --force`（`DEFER-I671-02`）。TC-0082/0083/0110/0220/0221/0222 的完整 am/branch 序列（`DEFER-I671-03`）。测试仓改动。

### 成功定义

- 两种 `checkout --orphan <same>` 形式均退出 0：索引清空、HEAD unborn、分支名不变、工作树文件保留。
- 清索引使用既有 `write_atomic`；替换前失败零变化、替换后失败 HEAD 不切且可重跑收敛；index 为符号链接时 fail-closed。
- `switch --orphan <same>` 与已提交同名分支仍 `LBR-CONFLICT-002` 拒绝；普通新名称 orphan 仍保留 start-point index。
- 文档与兼容矩阵同卡。

## 已决议设计决策

### ADR-ORP-01: 两种同名形式都成功，`switch` 与新名称契约不变

- **Status:** Accepted
- **Context:** 守卫不区分 `force`；Issue 正文与评论确认 Git 两形式都重建；`checkout --orphan <new>` 的既有契约是保留 index。
- **Decision:** 当前为同名 unborn orphan 时 `checkout` 两形式都进入重建；`switch --orphan <same>` 保持拒绝；非同名新 orphan 不清索引。
- **Consequences:** `checkout --orphan` 由 128 变 0；文档区分 checkout 与 switch。
- **Revisit when:** Git 改变 `--orphan`/`-f` 交互。

### ADR-ORP-02: 原子清索引与失败语义

- **Status:** Accepted
- **Decision:** `Index::new()` 保存到同目录唯一临时文件 → 读取字节 → `write_atomic(index_path, &bytes, true)` 原子替换 → 清理临时文件 → 更新 HEAD。替换前失败零变化；替换后 fsync 失败 HEAD 不切、可重跑收敛；index 为符号链接 fail-closed。
- **Alternatives considered:** `Index::save` 直接覆盖（跟随链接、无 fsync 语义）；先切 HEAD（分裂状态）。
- **Consequences:** 故障注入用 `write_atomic_with_post_replace_hook`（crate 内可见）并断言 checkout 调用路径的 HEAD/index。
- **Revisit when:** 索引层提供事务化 API。
