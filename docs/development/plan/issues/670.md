## 文档职责

### 适用范围

`libra reset` 与 `libra reset --hard` 在 **HEAD 未出生（unborn）且未给显式 target** 时的行为：索引清空、工作树文件保留、分支名与 unborn HEAD 不变；以及 `--soft` 的拒绝回归、显式 target（`reset --hard <commit>`）行为不变。

### 非目标

`--keep`/`--merge` 在 unborn 上的语义（`DEFER-I670-01`）。unborn 上的 pathspec reset（`DEFER-I670-02`）。`a`/`branch` 序列（`DEFER-I670-03..05`）。`switch --orphan`（`issues/671.md`）。测试仓改动。

### 成功定义

- unborn 隐式 HEAD 上 `reset`（默认 `--mixed`）与 `reset --hard` 均退出 0，索引清空（`libra ls-files` 无输出），工作树文件保留为未跟踪，`branch --show-current` 与 unborn HEAD 不变。
- `reset --soft` 仍以 `LBR-REPO-003` 拒绝；显式 target `reset --hard <commit>` 行为不变。
- 索引保存失败时不产生半清空状态（fail-closed）。
- 文档与兼容矩阵同卡。

## 已决议设计决策

### ADR-I670-01: 仅在「隐式 HEAD + unborn」时走清索引路径

- **Status:** Accepted
- **Context:** `run_reset()` 在 `resolve_commit`（`:942/969`）失败，`perform_reset` 的 `HeadUnborn` 守卫（`:2182`）在其后；显式 target 不应被 unborn 分流影响。
- **Decision:** 在 `run_reset()` 调用 `resolve_commit` 之前判定：当 `request.target` 为隐式 HEAD（未给 target）且 HEAD 为 unborn 时，`--mixed`（默认）与 `--hard` 走「清空索引 + 保留工作树」路径并退出 0；`--soft` 继续返回 `HeadUnborn`；给了显式 target 时保持现有解析与错误行为。
- **Alternatives considered:** 只改 `run_reset_patch()` 的 `:275`（不覆盖普通 reset）；在 `perform_reset` 内分流（解析已失败，无法到达）。
- **Consequences:** 显式 target 回归必须具名覆盖；`--keep`/`--merge` 不在本卡范围内（DEFER）。
- **Revisit when:** Git 改变 unborn 上 `reset` 的 mode 语义。

### ADR-I670-02: 索引清空复用既有保存路径并 fail-closed

- **Status:** Accepted
- **Context:** 已有 `reset` 头部与索引保存路径；本卡只需写空索引并保存。
- **Decision:** 在写入前先对 `index_path` 执行 `symlink_metadata`：若目标已存在且为符号链接，则立即返回专用的 `ResetError::SymlinkIndexUnsupported`（输出 "refusing to reset index: index is a symbolic link"）fail-closed 报错拒绝，稳定错误码映射为 `StableErrorCode::CliInvalidTarget`（LBR-CLI-003），提示用户移除或解引该符号链接，不跟随也不覆盖链接目标。确认非符号链接后，序列化空索引字节，在同目录创建隔离临时文件写入；普通路径调用 `src/utils/atomic_write.rs:71` 的 `write_atomic(index_path, &bytes, true)` 原子替换（临时文件 + 原子 rename + 目录 fsync）；在测试环境下通过内部 `write_atomic_with_post_replace_hook` 注入“替换完成但目录 fsync 之前”的错误。替换前失败（临时文件写/权限错误）保持原索引与 HEAD 零变化；替换后 fsync 失败报错但 HEAD 未切，再次运行命令幂等收敛。不得删除或覆盖工作树文件。
- **Alternatives considered:** 直接 `Index::save` 覆盖（跟随符号链接、无 fsync 语义）；先切 HEAD（分裂状态）。
- **Consequences:** 故障注入用例断言「替换前失败 ⇒ 索引/HEAD 均不变；替换后失败 ⇒ HEAD 未切且可重跑收敛」。
- **Revisit when:** 索引层提供事务化 API。

### ADR-I670-03: unborn HEAD 的输出契约与 schema 兼容

- **Status:** Accepted
- **Context:** `src/command/reset.rs:169` 的 `ResetOutput` 字段包含 `commit`、`short_commit`、`subject`；unborn HEAD 没有 commit。
- **Decision:** 人读文本模式保持 Git 静默（不打印 `HEAD is now at ...` 消息）；`--json`/`--machine` 模式保持现有 schema 字段类型不变（`String` 不改为 `Option<String>` 以免破坏反序列化），`commit`、`short_commit`、`subject` 固定填空字符串 `""`，`previous_commit` 保持 `None`，`files_unstaged` 填写实际从索引清空的条目数，`files_restored` 为 0。
- **Alternatives considered:** 将 commit 改为 `Option<String>`（破坏已有 JSON 消费者的强类型反序列化）；填伪 OID 全 0（产生不存在的对象哈希）。
- **Consequences:** 现有 JSON 消费者需接受空字符串 commit；由新增具名测试断言输出契约。
- **Revisit when:** 重构统一的 CLI 结构化输出协议。
