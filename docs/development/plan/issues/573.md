## 文档职责

本文处理 #573 的现行测试验收口径：三份主文档已由旧 v2.8 状态前滚到一致的 v2.16 分层，不重复修改；但 issue 第 5 条要求的贡献技能入口仍有真实冲突，`template/skills/libra.md` 继续无条件列出旧测试命令并引用已删除的 Web 构建开关。因此本计划采用 **docs / no-release**，分别审计权威规范与项目技能，再修复种子技能模板，不另造第三套政策。

### 适用范围

- 对照 `AGENTS.md`、`CLAUDE.md`、`docs/development/plan/plan-template.md` 的现行条款与历史迁移边界。
- 核对 `.agents/skills/libra-contribution-execution/SKILL.md`、`.agents/skills/libra-plan-task-authoring/SKILL.md`、`.agents/skills/libra-work-discovery/SKILL.md`、`.agents/skills/libra-issue-triage/SKILL.md`。
- 修改 `template/skills/libra.md` 的 Essential commands / Tests 与 Further reading：移除失效 `LIBRA_SKIP_WEB_BUILD`，删除无条件测试命令；有对应文档或所选卡时引用项目规范，缺失时给出可执行的项目级回退指导。
- 同步本计划、协调者维护的 `docs/development/plan/plan-status.md`，以及可终止的本地 C、直推 main 后 D 和 v2.14 终止链记录。

### 非目标

- 不修改当前已一致的 `AGENTS.md`、`CLAUDE.md` 或 `docs/development/plan/plan-template.md`。
- 不修改四个 `.agents/skills/*/SKILL.md`；它们或已引用 ER-13/ER-14，或不提供独立测试命令。若刷新发现新冲突，先修订计划。
- 不改变计划外第三门，也不把计划内全量/发布证据降级为 `cargo test --all`。
- 不追改历史计划和已执行发布的结果，不处理技能拆分，不修改产品代码、测试、CI、配置、版本面或发布通道。
- 不修复技能模板中与 issue 无关的其它历史文案；发现时应另行登记，不在本卡顺带清理。
- 不套用 v2.16 受限 `code-only`，不自动回复或关闭 issue。

### 成功定义

- `template/skills/libra.md` 不再提供独立、无条件或过期的测试政策，而是链接到当前权威入口。
- 主三文档和四个项目技能的核对结论均有真实行号；已正确文件保持不改。
- 四张卡的 AC/VER 按可独立失败的谓词/门准确计数；逐项审计政策语义和技能全文冲突，本计划及最终技能模板的引用分别检查目标与语义。
- 内容提交保留 `locally-accepted`；先在其同一 SHA 完成本地 C 测试与回滚，再推送并核对远端 ref，完整 C 到手后才记 `remote-pending`。后续状态提交按自身树复验并取得适用 D，不把旧树结果冒充新树结果。
- D 后在真实 `done/complete` 的 T 树运行计划级全量；E 只记已发生的 T 结果并自行跑适用本地检查。E 的真实结果写入计划且标明其实际被测树；若无法同时满足入库及最终树的明确要求，则停止而不伪造。末端 D 仅按预登记的 v2.14 延后登记。
