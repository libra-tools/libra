## 已决议设计决策

### ADR-554-01：真实三路语义与对象模式

**状态：** 修订中，待 R2 评审。**背景：** 固定 Git #15/16 不仅读取 index，还将有冲突结果写 blob。**决定：** 对象模式专用检查仓库和配置 hash kind；文件模式继续可在仓库外运行。先交付 `-p` 的受限 index、oid、冲突输出，再交付 clean 与冲突结果的 blob 持久化，未交付组合显式拒绝且在每次发布文档中披露。写入前验证全部输入；结果以内容寻址追加，不更新 index、refs 或工作树。**备选：** 把非 `-p` 写入延后，已被上游原案例否定；复用未筛选的通用 spec 会扩大访问面。**后果：** 已写入 blob 可能在错误后保留，不能自动删除；已发布实现按新版本前滚。**重审：** 参考 revision、资源边界或语法合同发生变化。
