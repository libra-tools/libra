## 已决议设计决策
### ADR-I676-01：只放行 unborn→target 的完全等价状态

- **Status:** Accepted；**Context:** staged 集合相对不存在的 HEAD 看似全新增，但可与目标提交完全相同；**Decision:** 仅当当前 HEAD unborn、index 等于目标 tree、worktree 相对 index 无 tracked 变化且无 target overwrite 时放行；**Alternatives:** 跳过全部 dirty 检查会丢数据，强制要求 `-f` 不匹配 Git cleanup；**Consequences:** 需要 checkout-specific 调用点与可复用等价比较；**Revisit:** Git 对非等价 staged/unstaged carry-over 提出独立 Issue 时。

## 网站文档交付门（ER-06a）

1. `SITE_ROOT=/Volumes/Sea/libra-backend`；`.libra/` 与 `.git` 必须恰有一个。前者用 `(cd "$SITE_ROOT" && libra status --short --branch)`，后者用 `git -C "$SITE_ROOT" status --short --branch`；歧义/缺失/脏状态即停。
