## 已决议设计决策

### ADR-I1055-01: 按 Git 的括号深度切路径，并去掉命令自己的第一处冒号切分

Git `object-name.c:1822-1830`（`6de20f6092`）：从左扫描，只有 `^` 或 `@` 紧跟 `{` 才让深度加一；裸 `{` 不加深度；深度为 0 的第一个 `:` 才是路径分隔。`}` 使深度减一。本卡在 `resolve_object_spec_typed`（`src/utils/util.rs:3075-3080`）用这条规则替换 `split_once(':')`。`:/` 前缀仍整段进入修订解析。找不到闭合 `}` 时不发明路径，把原字符串交给现有修订解析。

`show` 在进入共享解析器之前就 `split_once(':')`：`src/command/show.rs:411-415`、`:472-476`、`:1166-1170`。`ls-tree` 同样：`src/command/ls_tree.rs:213`。这三处（show 的展示、quiet 校验、JSON 收集）和 ls-tree 的 `resolve_treeish_to_tree` 改为调用同一个深度切分；不再各自认第一个冒号。日期 reflog、裸 `{` 配平、第二条搜索实现仍不是本卡。

`!-` / `!!` 只对 `:/…` 或 `<rev>^{/…}` 生效。原子为空时 `^{` 仍是 `invalid_reference`（`util.rs:2639-2680`）。测试必须写成 `HEAD^{/!-…}` 与 `HEAD^{/!!…}`，不实现裸 `^{/`。
