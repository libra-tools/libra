## 已决议设计决策

### ADR-LS-01: 分轴对齐 Git

Status: Accepted。Context: 两处失败相互独立但修改同一命令。Decision: 先目录，再格式；各卡包含代码、测试、文档及 patch 发布。目录过滤须在规范化时保留「有尾斜杠/作用域内容」的意图，不能仅删除空分量后以同一字符串决定输出。固定 Git 控制中 `path0/a` 命中树自身，`path3/` 命中子项；同时传 `dir dir//` 时仅输出目录子项，不能多输出目录自身；`-t` 本身不启用递归，`-r -t` 包含经过的树；子目录 `.` 表示其内容。其它重叠、多路径树序、缺失路径、重复尾斜杠与 blob 尾斜杠差异登记 DEFER-LS-02；不得把 Git #8 混合路径当前的兼容输出变成回归。gitlink 带尾斜杠继续保留现有输出，由 merge 回归守卫。大小格式属于同一轴：普通 `%(objectsize)` 也按 Git 返回 blob 实际大小，padded 同 `--long` 的最小七列（包括 `      -`），超过七列不截断。`--json --format` 不改变既有 size 字段与对象读取契约：未指定 `--long` 时 JSON 不因格式 atom 加入 size 或读取 blob。Alternatives: 一张混合卡会耦合恢复；将文档单拆会提前公开不完整行为。Consequences: 重复发布成本；开工时 Git 或当前实现有漂移先修订计划。Revisit: Git 对照或 Issue 范围改变。

路径遍历不得比原实现增加一次全树扫描；size 延续既有每 blob 至多一次加载成本，非 size 输出零额外 blob 读取；无存储/schema 增长。执行时以同一 fixture 的 blob 数和大小、读取次数及峰值内存对比改动前后，超出既有量级先修计划。
