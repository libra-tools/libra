### 成功定义

- 非 root、非 merge 的单提交有匹配差异时默认先输出完整 commit id，再输出与 `diff-tree <parent> <commit>` 相同的 diff；无匹配差异、root（未给 `--root`）或 merge（未给 `-m`/`-c`/`--cc`）的默认形式为空输出且退出 0（以 Git 对照测试为证）；既有 `--root` 的 raw 与 `-p` 输出保持完整；无效 revision 稳定返回 `LBR-CLI-003`（退出 128），对象读取失败稳定返回 `LBR-REPO-002`（退出 128），均不得退化为空成功。
- 单提交 `-s` 保留 commit id；`--quiet` 禁用全部 stdout 输出并在有差异时退出 1（与 `--no-commit-id --quiet` 输出等价）；`--json`、`--machine` 与 `--output`（含正例、root 与 `-s` 无 body 场景）均走共享渲染/输出通道并统一使用既有 `"diff"` 结构化信封，不混入 wrapper `println!` 文本头。
- `--no-commit-id` 只去掉该头部，不改变 diff 体或退出码；双 tree-ish 形式接受该选项且输出不变，并具备共享渲染、`DIFF_TREE_EXAMPLES` 与结构化输出回归。
- `--stat` 单独输出 diffstat；`--stat -p` 先输出 diffstat、一个空行，再输出 patch；issue 点名的 `--no-commit-id --stat -p <commit>` 可生成 patch fixture。
- `--full-index` 让 patch `index` 行使用完整前后对象 id，raw 与 JSON schema 不变。
- 每项行为有具名新用例；EN、zh-CN、网站、开发文档与 `COMPATIBILITY.md:228` 同卡同步。
- 四张实现卡各自完成独立 `patch` 发布（DTR-01 连同原 DTR-06 的边界同卡发布）；DTR-05 取得钉版上游复跑并按实际结果记录 DEP-DTR-04/05 的剩余阻塞，缺证据时保持 blocked；CLOSE-555 全绿。

## 已决议设计决策

### ADR-DTR-01：以后写评论和当前 main 定范围，不承诺级联用例自动通过

- **Status:** Accepted
- **Context:** 当前源码已接受 `-s` / `-c`；后续评论证明 `--no-commit-id`、单提交、`--stat`、`--full-index` 是剩余直接缺口，同时也列出 format-patch/am/reset/layout 依赖。
- **Decision:** 实现 GAP-01..04；combined 渲染与未要求选项延后。DTR-05 只按新公开结果判断用例，不能用“diff-tree 卡完成”替代 t4150/t4103 结论。
- **Alternatives considered:** 重复实现 `-s` / `-c` 无意义；把 format-patch/am/reset 一并纳入会形成多命令巨型计划。
- **Consequences:** #555 可因 DEFER-DTR-01 或其它 issue 的引用用例继续保持 OPEN。
- **Revisit when:** 新评论改变根因归属，或 529/536/547 与布局决策交付后。

### ADR-DTR-02：单提交解析、Git root/merge 契约与 commit id 头接入共享渲染

- **Status:** Accepted
- **Context:** `0.30.205`（`#478` LG-09）已在 `DiffTreeArgs` 中实现 `tree_b: Option<String>`、`--root` 与原生 raw 渲染，但存在四项问题：（1）`execute_tree_delegated` 直接 `println!("{id}")` 并忽略 `--root`，`execute_tree_raw` 直接 `print!("{lines}")` 且未接入 `OutputConfig`/既有 `"diff"` 结构化信封，绕过 pager、`--output` 与结构化隔离；（2）当前实现与 `diff_plumbing_test.rs:1191`、`docs/commands/diff-tree.md:27` 将无 `--root` 的 root 提交写成打印 `{id}\n`，而真实 Git 对照探针（P-DTR-05）证明 `git diff-tree <root>` 输出为空且退出 0；同时 `--quiet` 在 `render.rs:226`、`diff_plumbing.rs:509`、`docs/commands/diff-tree.md:48` 与 `diff_plumbing_test.rs:276-295` 均规定禁用全部 stdout 输出并在有差异时退出 1（与 Git `--quiet` 文档契约一致）；（3）`resolve_commit` / `resolve_tree_id` 返回无稳定码的 `CliError::fatal`（128），`diff.rs:722-727` 将 `InvalidRevision` 映射为 `LBR-CLI-003`、`ObjectLoad` 映射为 `LBR-REPO-002`（128），而文档 `:63` 误写 129；（4）`execute_tree_delegated` 尚未支持 `--root`。
- **Decision:**
  - 保留 `0.30.205` 已公开的 `tree_b: Option<String>` 与 `--root`、`--recurse`（`-r`）、`--tree-entries`（`-t`）能力；恰有一个 parent 时合成 `--old <parent> --new <commit>`；root 在无 `--root` 时或 merge 在无父选择时严格对齐 Git（先以 Git 对照测试锁定 root/merge 行为，再修改渲染器），返回空输出与退出 0。
  - 为 `DiffTreeArgs` 新增 `#[clap(long, value_name = "FILENAME")] pub output: Option<String>`（与 `DiffArgs::output` 一致）：委托分支将其通过 `--output <path>` 转发给 `DiffArgs`；原生 raw 分支将最终渲染写入该路径（I/O 失败映射为 `DiffError::OutputWrite` / `IoWriteFailed`，退出 128）并保持 stdout 为空。
  - 在 `DiffArgs` 增加隐藏 `plumbing_commit_id: Option<String>` 与 `plumbing_empty_old: bool`（由 wrapper 注入）：`compare.rs::resolve_diff_side` 在 `plumbing_empty_old && !is_new` 时返回空 `DiffSide`（空 `blobs`/`modes`，`is_worktree: false`），使 `--root -p`（及 `--root --name-only`/`--name-status`）能对空树比较并输出创建 diff。原生 `execute_tree_raw` 继续保留非递归默认 raw 与 `-r -t` tree-entry 语义，但不再裸调用 `print!("{lines}")`，而是统一接入 `OutputConfig`：文本模式走 `--output` 写文件或 `Pager::with_config`；结构化模式（`--json` / `--machine`）统一采用**既有 `"diff"` 命令信封契约**（`emit_json_data("diff", &diff_output, output)`：`--json` 输出 Pretty JSON + `\n`，`--machine` 输出 NDJSON 紧凑单行 + `\n`，`DiffOutput` 字段与 `diff --json` 完全一致，不新增 schema，不混入文本 commit id 头；无差异或 root 无 `--root` 时返回 `files_changed: 0, files: []` 的 `"diff"` 信封）。
  - 共享渲染器仅在过滤后存在匹配差异（或 `--root` 对空树有差异）时为人读输出前置 `<oid>\n`；此时即使 `no_patch` 的 body 为空仍输出头部。无差异（含路径过滤掉全部差异）则无头部（P-DTR-07）。
  - `plumbing_quiet`（`--quiet`）保持全静默退出契约（包括单提交、`--no-commit-id --quiet`、`--json --quiet` 与 `--machine --quiet`）：始终保持 stdout 为空，有差异时退出 1，无差异时退出 0；`--json` / `--machine` 与 `--output` 均走统一输出通道，结构化模式不增加字段、不输出人读头部。
  - 错误路径在 raw 与委托路径统一：无效 revision 映射为 `LBR-CLI-003`（`StableErrorCode::CliInvalidTarget`）且退出 128（与 `tests/command/diff_plumbing_test.rs:299-305` 及 Git fatal 128 一致，同步更新 `docs/commands/diff-tree.md:63` 与 `COMPATIBILITY.md:228`）；对象加载失败映射为 `LBR-REPO-002`（`StableErrorCode::RepoCorrupt`，对应 `DiffError::ObjectLoad`）且退出 128；不得把读取失败退化为 root/merge 空成功。
- **Alternatives considered:** 保留 wrapper `println!` 会继续绕过 pager/`--output` 并污染 `--json`/`--machine`；让 `--quiet` 打印 commit id 会破坏既有 `render.rs:226`/`diff_plumbing.rs:509`/`diff_plumbing_test.rs:276-295` 与 Git `--quiet` 文档契约；为 raw 另造新 JSON schema 会破坏机器消费者兼容性。
- **Consequences:** 需同步更新 `tests/command/diff_plumbing_test.rs:1191` 的旧 root-id-only 断言与 `docs/commands/diff-tree.md:27,63`、`docs/development/commands/diff-tree.md:10,11,33`、`COMPATIBILITY.md:228`（含修正 `-r` 非空操作语义），并补充 `--root` raw/patch 保护回归及正例 `--json`/`--machine`/`--output` 回归；`-m` 与完整 combined 渲染仍明确延后。
- **Revisit when:** 实现 `-m` 或完整 combined diff 时。

### ADR-DTR-03：`--no-commit-id` 只抑制头部

- **Status:** Accepted
- **Context:** `0.30.205` 的 `DiffTreeArgs` 已解析 `no_commit_id` 且已有基础测试（`diff_plumbing_test.rs:1156`），但尚缺迁入共享渲染器后的 `--quiet`、`-s`、双树、`--json`/`--machine`/`--output` 全量回归以及 `DIFF_TREE_EXAMPLES`/文档对齐。P-DTR-02 证明该选项不改变 diff 体；双树没有头部但接受选项。
- **Decision:** 在 `0.30.205` 已解析 `no_commit_id` 的基础上，迁移至共享渲染后单提交时不注入隐藏 `plumbing_commit_id` 头部，双树不注入且不改变输出。`-s` / `--quiet` 的退出码、stat+patch 和 full-index 与该选项正交；同步更新 `DIFF_TREE_EXAMPLES` 与文档/矩阵。
- **Alternatives considered:** 在最终字符串中删除第一行会误删用户 patch 内容且污染 JSON；让该选项暗示 no-patch 与 Git 不符。
- **Consequences:** issue 的 `--no-commit-id --stat -p <commit>` 由 DTR-02 与本卡共同使能，完整组合由 DTR-03 验收。
- **Revisit when:** 未来机器输出 schema 显式加入 commit 元数据时；本计划不做。

### ADR-DTR-04：stat 与显式 patch 一次计算、按序组合

- **Status:** Accepted
- **Context:** 共享引擎已有 diffstat，但 `stat` 当前抑制 patch；P-DTR-03 要求 diffstat、空行、patch。
- **Decision:**
  - `DiffTreeArgs` 增加 `stat` 并转发；stat 单独存在时不再由 wrapper 默认追加 raw。
  - 复用/引入隐藏 `plumbing_patch`，表示“显式 patch 与 raw/stat 并存”。`stat && plumbing_patch` 在一次 `run_diff` 后渲染 `diffstat + "\n\n" + patch`；`patch_body_is_shown` 对该隐藏组合返回 true。
  - 隐藏标记只由 plumbing wrapper 注入，porcelain `diff --stat` 保持现状。#544 拟议由 DFF-04 统一交付该标记及其驱动、结构化隔离，尚未确认；两稿稳定后协调者核对实际契约。若对方先交付且满足本卡语义则复用并验证，不新建第二份组合 helper。
  - JSON 不拼接文本；`--no-commit-id` 只控制 ADR-DTR-03 的头部。
- **Alternatives considered:** 只转发 `--stat` 会丢失 patch；运行两次引擎会重复对象和工作树 I/O，并造成 pager/JSON 不一致。
- **Consequences:** `diff-tree --stat -p` 与 issue 点名命令具备 Git 顺序；`--stat --raw` 等未要求组合不扩展。
- **Revisit when:** 共享渲染器正式建模多输出模式时。

### ADR-DTR-05：`--full-index` 只做定向转发

- **Status:** Accepted
- **Context:** 共享引擎已实现 `--full-index` 的 patch index 行改写，且有既有行为测试；第 21 条评论把 diff-tree 的该选项列为 t4103 setup 的直接缺口，但 setup 中其它选项的具体失败尚未在钉版复跑前确认。
- **Decision:** 在 `DiffTreeArgs` 增加 `full_index` 并在合成 argv 追加 `--full-index`；不改变 raw、rename、exit-code 或 JSON 规则，不顺带开放 `--binary` 等其它选项。
- **Alternatives considered:** 在 plumbing 内重写 index 行会复制引擎逻辑；开放整个 porcelain flag surface 超出 issue。
- **Consequences:** 只能声称本卡使 `diff-tree --full-index` 可用并闭合该单一选项缺口；t4103 的 TC-3096/3097 与 `apply` 后续行为必须由 DTR-05 钉版复跑重新判定，本卡不预先宣布 setup 全绿。
- **Revisit when:** 有新 issue 要求更多 diff 选项时。

  ```bash
  # 执行前按 ER-06a 验证隔离克隆在 cf，HEAD 等于记录的 origin/cf SHA。
  # 两个变量必须是已核验的绝对路径，LIBRA_DOC_ROOT 指本卡最终源码树。
  python3 -I - "$LIBRA_DOC_ROOT" "$BACKEND_CF_CLONE" <<'PY'
  import hashlib
  import importlib.util
  import os
  from pathlib import Path
  import sys
  import tempfile

  source, backend = map(Path, sys.argv[1:])
  if not source.is_absolute() or not backend.is_absolute():
      raise SystemExit('absolute source and backend paths required')
  script = backend / 'scripts/sync-libra-command-docs.py'
  spec = importlib.util.spec_from_file_location('command_doc_sync', script)
  if spec is None or spec.loader is None:
      raise SystemExit('cannot load reviewed sync script')
  sync = importlib.util.module_from_spec(spec)
  spec.loader.exec_module(sync)
  report = sync.synchronize(source, backend, False, 'libra', {'diff-tree'})
  directory = backend / 'apps/tanstack-app/content/docs/commands'
  target = directory / 'diff-tree.en.md'
  original = sync.regular(target)
  source_path = source / 'docs/commands/diff-tree.md'
  body = sync.regular(source_path)
  cli = sync.regular(source / 'src/cli.rs')
  names = {c['name'] for c in sync.parse_root_commands(cli.decode())}
  existing = {p.name.rsplit('.en.', 1)[0] for p in directory.iterdir()
              if p.name.endswith(('.en.md', '.en.mdx'))}
  guides = {n for n in ('repository-hooks', 'send-email')
            if (source / f'docs/commands/{n}.md').exists()}
  available = (existing - ({'gc', 'prune', 'stats'} - names)) | names | guides | {'index'}
  new = (sync.frontmatter('diff-tree', original.decode()) +
         sync.rewrite_body('docs/commands/diff-tree.md', body.decode(), available, source)).encode()
  drift = report['drift']
  if new != original:
      if len(drift) != 1 or drift[0]['path'] != str(target.relative_to(backend)) or \
         drift[0]['after_sha256'] != hashlib.sha256(new).hexdigest():
          raise SystemExit('unexpected drift or generated hash')
      if sync.regular(target) != original or sync.regular(source_path) != body or \
         sync.regular(source / 'src/cli.rs') != cli:
          raise SystemExit('input changed; repeat verification')
      fd, name = tempfile.mkstemp(prefix='.libra-doc-sync-', dir=directory)
      try:
          with os.fdopen(fd, 'wb') as out:
              os.fchmod(out.fileno(), target.stat().st_mode & 0o777)
              out.write(new)
          os.replace(name, target)
      finally:
          if os.path.exists(name):
              os.unlink(name)
  elif drift:
      raise SystemExit('unexpected drift')
  if sync.synchronize(source, backend, False, 'libra', {'diff-tree'})['drift']:
      raise SystemExit('post-write drift')
  print('diff-tree synchronized, sha256=' + hashlib.sha256(new).hexdigest())
  PY
  ```
