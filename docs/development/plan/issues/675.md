## 文档职责

### 适用范围

`libra branch -M [<old>] <new>` 与其等价写法 `libra branch -m -f <old> <new>` 的解析、非锁定目标覆盖、当前 HEAD 跟随、锁与 worktree 安全边界，以及该 setup 对 `--track`、`--merged`、`--verbose`、TC-0153 和 TC-0246 的解锁。
### 非目标

普通 `-m` 的 reflog/config 全量 Git 对齐、symref 重命名（`issues/556.md#SY-05`）、remote HEAD 读取错误（`issues/541.md#URM-07`）、测试用例仓修改，以及评论中除 TC-0246 外的每个 TC 均不在本计划内；后者逐条登记于「非目标与延后项」，不得由概括性范围文字替代。
### 成功定义

- `-M <old> <new>` 与 `-m -f <old> <new>` 具备同一 Git 强制覆盖语义并保留既有 `main`/AI ref 的 fail-closed 保护；t3201 setup、tracking 与两种 merged listing 精确通过；上游 #24、TC-0153、TC-0246、命令文档、兼容矩阵和网站同卡交付。

1. **双 VCS 识别：** 执行以下判定；两者同时存在或同时不存在即停止。后续命令只走选中的一支。
   ```bash

   SITE_PAGE=apps/tanstack-app/content/docs/commands/branch.en.md
   if [ -d "$SITE/.libra" ] && [ ! -e "$SITE/.git" ]; then SITE_VCS=libra
   elif [ -e "$SITE/.git" ] && [ ! -d "$SITE/.libra" ]; then SITE_VCS=git
   else echo 'ERROR: ambiguous or missing VCS metadata' >&2; exit 1; fi
   ```

2. **`cf` 切换与复核：** 在步骤 1 的同一 shell 复制执行；任一断言失败即停止。若原 checkout 干净但有无关超前提交，按模板 ER-06a 在 `mktemp -d` 隔离 clone `cf`，并在 clone 中从步骤 1 重跑。
   ```bash
   set -euo pipefail
   if [ "$SITE_VCS" = libra ]; then
     (cd "$SITE" && libra status --short --branch)
     if [ "$(cd "$SITE" && libra branch --show-current)" != cf ]; then (cd "$SITE" && libra switch cf); fi
     (cd "$SITE" && libra fetch origin cf)
     test "$(cd "$SITE" && libra branch --show-current)" = cf

     test "$(git -C "$SITE" branch --show-current)" = cf

     test "$SITE_TRACKING_BASE" = "$SITE_REMOTE_BASE"
   fi

   test "$SITE_LOCAL_BASE" = "$SITE_REMOTE_BASE"
   SITE_REMOTE_BEFORE="$SITE_REMOTE_BASE"
   ```

3. **页面与前端门：** 只修改 `$SITE_PAGE`，然后执行：

4. **人工 Claude Code PASS 收据：** 4a 先打印供审查输入的差异 SHA-256；4b 由人工完成 Claude Code 审查后在同一 shell 明确 export 三个收据变量；4c 再校验收据与当前差异一致，任一步失败即停止。
   ```bash

   if [ "$SITE_VCS" = libra ]; then SITE_DIFF_SHA256="$(libra diff -- "$SITE_PAGE" | sha256sum | awk '{print $1}')"
   else SITE_DIFF_SHA256="$(git diff -- "$SITE_PAGE" | sha256sum | awk '{print $1}')"; fi

   ```
5. **精确 staged allowlist、签名+DCO 与远端 ref 租约：** staged 集合必须恰为该页；提交后固定一次 SHA，并对同一 SHA 核验 `gpgsig` 与 `Signed-off-by`。复制执行：
   ```bash
   set -euo pipefail
   if [ "$SITE_VCS" = libra ]; then
     (cd "$SITE" && libra add "$SITE_PAGE")
     test "$(cd "$SITE" && libra diff --staged --name-only)" = "$SITE_PAGE"
     (cd "$SITE" && libra commit -S -s -m 'docs(branch): document force rename')

     (cd "$SITE" && libra log -1 --only-trailers --trailer Signed-off-by "$SITE_HEAD" | rg -q '^    Signed-off-by: ')

     test "$SITE_REMOTE_PRE_PUSH" = "$SITE_REMOTE_BEFORE"
     (cd "$SITE" && libra push origin cf)
     SITE_REMOTE_AFTER="$(cd "$SITE" && libra ls-remote origin refs/heads/cf | awk 'NR==1 {print $1}')"
   else
     git -C "$SITE" add "$SITE_PAGE"
     test "$(git -C "$SITE" diff --cached --name-only)" = "$SITE_PAGE"
     git -C "$SITE" commit -S -s -m 'docs(branch): document force rename'
     SITE_HEAD="$(git -C "$SITE" rev-parse HEAD)"
     git -C "$SITE" cat-file -p "$SITE_HEAD" | rg -q '^gpgsig '
     git -C "$SITE" show -s --format=%B "$SITE_HEAD" | rg -q '^Signed-off-by: '
     git -C "$SITE" verify-commit "$SITE_HEAD"
     test "$(git -C "$SITE" rev-parse "$SITE_HEAD^")" = "$SITE_REMOTE_BEFORE"
     SITE_REMOTE_PRE_PUSH="$(git -C "$SITE" ls-remote origin refs/heads/cf | awk 'NR==1 {print $1}')"
     test "$SITE_REMOTE_PRE_PUSH" = "$SITE_REMOTE_BEFORE"
     git -C "$SITE" push origin HEAD:refs/heads/cf
     SITE_REMOTE_AFTER="$(git -C "$SITE" ls-remote origin refs/heads/cf | awk 'NR==1 {print $1}')"
   fi
   test "$SITE_REMOTE_AFTER" = "$SITE_HEAD"
   test "$SITE_REMOTE_AFTER" != "$SITE_REMOTE_BEFORE"
   printf 'site_before=%s\nsite_head=%s\nsite_after=%s\n' "$SITE_REMOTE_BEFORE" "$SITE_HEAD" "$SITE_REMOTE_AFTER"
   ```
6. **有界部署轮询：** 最多 20 次、每次间隔最多 15 秒、总预算 300 秒；每次 `curl --max-time` 使用剩余预算与 15 秒的较小值。只有 HTTP 200、固定句恰一处且正文 SHA-256 已打印才通过。
   ```bash
   SITE_URL=https://libra.tools/docs/commands/branch
   SITE_SENTENCE='Force rename keeps existing main and AI-managed branches protected.'
   started="$(date +%s)"; ok=0
   for attempt in $(seq 1 20); do
     now="$(date +%s)"; remaining=$((300 - (now - started))); [ "$remaining" -gt 0 ] || break
     req_timeout=15; [ "$remaining" -lt 15 ] && req_timeout="$remaining"
     body="$(mktemp)"; code="$(curl -sS --max-time "$req_timeout" -o "$body" -w '%{http_code}' "$SITE_URL" || true)"
     hits="$(grep -Fo "$SITE_SENTENCE" "$body" | wc -l | tr -d ' ')"
     if [ "$code" = 200 ] && [ "$hits" -eq 1 ]; then sha256sum "$body"; ok=1; rm -f "$body"; break; fi
     rm -f "$body"; [ "$attempt" -lt 20 ] || break
     now="$(date +%s)"; remaining=$((300 - (now - started))); [ "$remaining" -gt 0 ] || break
     pause=15; [ "$remaining" -lt 15 ] && pause="$remaining"; sleep "$pause"
   done
   test "$ok" -eq 1
   ```
