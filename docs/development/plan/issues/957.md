## 已决议设计决策

### ADR-957-01: fixed token 不读取 `date_mode`

- **Status:** Accepted；**Context:** `%ad/%cd` 使用 `self.date_mode`；**Decision:** 六个 token 走固定分支，永不读 `--date/log.date`；**Alternatives:** 改写 `date_mode`（会破坏 Git 合同）；**Consequences:** configurable/fixed 两组测试分开；**Revisit:** Git 改变 pretty 规范时。
### ADR-957-02: fixed/configurable 共用签名时区与 human 单一事实源

- **Status:** Accepted；**Context:** signature 保存 `+HHMM`；Git pin `date.c:221-368` 的 `DATE_HUMAN` 走 `show_date_normal`（仅当天使用 relative，旧日期/跨年/未来日期各有独立格式），`text::relative_date_at` 只覆盖 relative 分支；**Decision:** fixed/`short`/`iso`/`iso-strict` 共用签名感知格式化；`human` 必须实现 `show_date_normal` 的完整分支（当天 relative、同年不同日、跨年与未来日期各自格式），不得直接复用 relative helper；**Alternatives:** 全部 UTC 或复用 relative（拒绝，会上旧日期/跨年差异）；**Consequences:** human 需覆盖近期/旧日期/跨年/未来/时区五组字节级 Git 对照；**Revisit:** 引入可注入全局 clock 时。
### ADR-957-03: 共享 renderer 同时约束三命令

- **Status:** Accepted；**Context:** show/shortlog 复用 `CommitFormatter`；**Decision:** 同卡验证并文档化三命令；**Alternatives:** 只测 log（会留下静默漂移）；**Consequences:** T-1 全量门；**Revisit:** 消费者拆分 renderer 时。
