# Issue #631：vault 签名决策必须显式且无静默降级（2026-11-11）

> 模板 v2.16。[Issue #631](https://github.com/libra-tools/libra/issues/631) OPEN，无评论。仅规划，未授权执行；卡 `pending` / 验收空。基线 SHA/版本由开工门现场刷新。Git 对照 pin `6de20f6092dcf9bdb1c8efe03db4b70c82b423dd`。测试用例仓 `/mnt/gitmono/libra-testcases` 本计划不修改。

## 文档职责

### 适用范围

`libra commit`、`commit --amend`、`merge`、`cherry-pick` 的 vault 签名决策：`vault.signing` 读取与 Git 布尔语义、`commit.gpgSign`/`--[no-]gpg-sign` 优先级、unseal key 缺失错误、策略组合对 `gpgsig` 头的可观察结果，以及签名失败时对象库残留边界。

### 非目标

密钥存储格式（永久非目标）。`gpg.program`/SSH 签名（`DEFER-I631-01`）。`merge --verify-signatures` 成功/信任文案（`DEFER-I631-02`，无对应计划文件）。`init` 默认 `vault.signing=true` 差异（`DEFER-I631-03`）；既有未签名历史的复核/声明口径（`DEFER-I631-04`，属仓库治理）。

### 成功定义

- 签名已启用（配置为真且 unseal key 可用）时提交对象带 Git 兼容 `gpgsig`，`-S/--gpg-sign` 强制路径同样产出。
- 配置读取失败、非布尔值、unseal key 缺失时 fail-closed（稳定错误码、非零退出），不再静默未签名。
- 显式关闭（`commit.gpgSign=false`、`--no-gpg-sign`）不签名且退出 0。
- commit/amend 与 merge/cherry-pick 共用同一判定，回归与文档同卡。

## 已决议设计决策

### ADR-SIG-01: 复用单一 Git 布尔解析

- **Status:** Accepted
- **Context:** `commit.rs` 内私有布尔实现与 `internal/config.rs` 权威实现语义分叉，导致 `TRUE`/`1` 等合法写法被当作 false。
- **Decision:** `vault.signing` 与 `commit.gpgSign` 一律经 `internal::config::parse_git_config_bool`；删除 `src/command/commit.rs:2195` 私有副本，非布尔值按配置错误失败。
- **Alternatives considered:** 内联字符串匹配（保留双语义）。
- **Consequences:** 非布尔配置由「静默不签」变错误，需文档登记。
- **Revisit when:** 配置层引入统一布尔类型。

### ADR-SIG-02: fail-closed 且允许已持久化 tree 残留

- **Status:** Accepted
- **Context:** `src/command/commit.rs:1347` 在签名前持久化 tree。
- **Decision:** 签名失败必须阻止 commit 对象落库与 HEAD 更新；已持久化 tree 作为孤儿对象允许残留，由 `fsck`/GC 处理，不重排对象写入顺序。
- **Alternatives considered:** 先签名后持久化（跨对象层写集）。
- **Consequences:** 故障矩阵记录允许残留。
- **Revisit when:** 对象库支持事务化写入。

```bash

ISO="$(mktemp -d)"; trap 'rm -rf "$ISO"' EXIT
(cd "$ISO" && libra init . >/dev/null)                    # 失败即停止（不使用 || true）
(cd "$ISO" && libra remote add origin "$ORIGIN_URL")
(cd "$ISO" && libra fetch origin main)
(cd "$ISO" && libra checkout --detach "$NEW_REMOTE")
libra bundle create "$ISO/local.bundle" "$CARD_SHA"       # 把本地提交带到隔离仓库

(cd "$ISO" && libra cherry-pick -n "$CARD_SHA")           # 只应用改动，不产生提交
```
