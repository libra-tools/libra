## 已决议设计决策

### ADR-698-01: 列槽宽按 `max_rendered_len + 1` 语义，总宽受 COLUMNS 限制

- **Status:** Accepted
- **Context:** Git 按「已渲染条目最大宽度 + 1」为槽宽（`--column=column`），并在 `COLUMNS` 内换行；Libra 当前每槽多 1 空格。
- **Decision:** 只改 `format_branch_columns`：以**终端显示宽度**（CJK/组合字符按宽度 2/0 计算，使用既有 `unicode-width` 或等价 helper）对已渲染条目求 `max_rendered_width`，槽宽 = `max_rendered_width + 1`（本夹具 `2+5+1=8`）；可用宽度取 `column_layout_width()`，边界为 `term_columns - 1`；`list_name_column_width`（仅 `-v/-vv`）保持不变。
- **Alternatives considered:** 硬编码 8（对更长分支名错误）。
- **Consequences:** 现有 9 槽输出变 8/更长名自适应；`--no-column` 不变。
- **Revisit when:** Git 改变 `--column` 宽度算法。
