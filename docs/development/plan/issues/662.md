# Issue #662：空仓库的根 pathspec 必须成功（2026-11-11）

> 模板 v2.16。[Issue #662](https://github.com/libra-tools/libra/issues/662) OPEN，无评论。仅规划，未授权执行；卡 `pending` / 验收空。Git 对照 pin `6de20f6092dcf9bdb1c8efe03db4b70c82b423dd`；判据来源 `t/t3700-add.sh#35/#36`（本机未运行）。测试用例仓 `../libra-testcases` 本计划不修改。

## 文档职责

### 适用范围

`libra add` 的 pathspec 未匹配判定在**空仓库**（无 HEAD 提交、索引为空）上的行为：`add -A .`、`add -A -- .`、`add --all .`、`add .`、`add :/` 的退出码与输出，以及无 pathspec 的 `add -A` 回归；非空仓库与含非根元素的混合输入保持既有失败语义。

### 非目标

通配符与 magic pathspec（`:(attr)`/`:(glob)`/`:(exclude)`、以及作为空 sentinel 的裸 `:`）的新语义。单独的 `:(exclude).` 保持今天的退出码 0，并仍执行 `save_index`。「未匹配」错误码与文案改版（`docs/error-codes.md` 不变）。`--ignore-missing` 警告路径（`src/command/add.rs:2722-2744`）。`--resolved` 冲突解决路径（`src/command/add.rs:1371-1397`，仅用于未合并索引条目）。`add -N/--intent-to-add` 的未匹配报错（`src/command/add.rs:1526-1535`）。`restore`/`checkout`/`rm` 的同名文案。

### 成功定义

- 空仓库上五种根 pathspec 形式（`add -A .`、`add -A -- .`、`add --all .`、`add .`、`add :/`）均退出 0、stdout/stderr 为 0 字节、索引无条目。
- 无 pathspec 的 `add -A` 保持退出 0、stdout/stderr 为 0 字节、索引无条目（回归，不得因本卡回归）。
- 空仓库上 `add nonexistent`、`add . nonexistent`、`add :/ nonexistent` 与非空仓库未匹配 pathspec 仍以 `LBR-CLI-003` 家族错误（`CliInvalidTarget`）非零退出，且 stderr 含被拒绝的 pathspec 字面量。
- 非空仓库 `add -A .` 退出 0 且实际暂存工作区文件。
- 回归、三处 add 文档、`COMPATIBILITY.md` 与网站 `commands/add.en.md` 同卡交付。

### ADR-EMPTY-01: 按元素对「解析后指向仓库根的 pathspec + unborn 仓库」放行

- **Status:** Accepted
- **Context:** `libra add` 以「匹配到 tracked 变更或工作树文件」为成功条件；空仓库无候选，故根 pathspec 被判未匹配。此外 `resolve_body`（`src/utils/pathspec/mod.rs:407`）以当前工作目录为基准解析 `.`：在子目录 `sub/` 中执行 `add .` 解析为 `sub` 而非仓库根，若按原始字符串 `.` 放行会误放行子目录调用；而仅在「全集只含根型元素」时整批放行又会让混合输入（如 `add . nonexistent`）在顺序校验时先误报 `.` 未匹配。
- **Decision:** 当仓库无 HEAD 提交且索引为空时，在 `validate_pathspecs` 的未匹配循环中**按元素**放行 `PathspecSet::is_plain_repo_root_positive` 为 true 的 pathspec。该谓词是本卡在 `src/utils/pathspec/mod.rs` 的 `PathspecSet` 上新增的方法（紧挨 `positive_spec_match_path`，`src/utils/pathspec/mod.rs:219`）：只在该 raw 是 positive spec、归一化 workdir 相对路径为空、且没有任何 `:(...)` 长 magic 时返回 true。短写 `:/`（`parse_magic` `:359-363` 的 top 简写，body 为空）是 Issue 点名的第五种写法，允许。`:(top)`、`:(top).`、`literal`、`glob`、`icase`、`exclude`（`:384-400`）都返回 false，仍属于 `DEFER-I662-01`。`unmatched_positive_specs`（`src/utils/pathspec/mod.rs:188-199`）丢掉 exclude spec，所以单独的 `:(exclude).` 到不了 `AddError::PathspecNotMatched`（`src/command/add.rs:2759-2761`），而是走到今天的无正匹配成功路径：校验通过后没有待暂存文件，`save_index`（`:2229`）仍执行，退出码为 0。`has_positive()`（`:129-133`）对这种集合为 false。新的空仓库 no-op 提前返回只适用于 pathspec 集合为空，或每个 spec 都是 `is_plain_repo_root_positive`。exclude-only 不属于这两种，必须继续执行到 `save_index`。本卡不给 exclude-only 新增拒绝规则。现有 `positive_spec_match_path` 只给出归一化路径，不能单独用来放行。例子：仓库根的 `.`、子目录中的 `..`、`:/`，以及无 pathspec 时 `-A/--all` 的隐式全树路径。该元素不触发 `PathspecNotMatched`，命令在仅含此类元素时退出 0 且不写索引。子目录中执行的 `add .`（解析为 `sub`）不满足根路径条件，仍报 `PathspecNotMatched`；裸 `:`（Git 的空 pathspec sentinel）不纳入放行集合，保持现状并登记 `DEFER-I662-01`。混合输入中的非根未匹配元素（如 `add . nonexistent`、`add :/ nonexistent`）仍触发 `AddError::PathspecNotMatched { pathspec }` 并报出该非根字面量。工作区存在待暂存文件时候选集非空，走既有暂存路径。
- **Alternatives considered:** 空仓库忽略全部 pathspec（会让 `add nonexistent` 静默成功）；把 `.` 恒视为匹配（非空仓库语义被放宽）。
- **Consequences:** 判定依赖 unborn 事实；`add -A .` 与 `add .` 的库内路径不同但结果一致。
- **Revisit when:** Git 改变 `t3700` 空仓库 expectations，或需要支持裸 `:`。

### ADR-EMPTY-02: 不新增错误码，只在普通收集判定点收窄

- **Status:** Accepted
- **Context:** 既有 `LBR-CLI-003` 家族文案保留；`--resolved`（`src/command/add.rs:1371-1397`）仅面向存在未合并索引条目的仓库，不在空仓库放行范围内。
- **Decision:** 仅在普通收集判定点 `validate_pathspecs`（`src/command/add.rs:2759-2761`）收窄，并通过显式布尔参数 `allow_empty_repo_root_pathspecs: bool` 隔离调用方：仅普通 `add` 路径（`src/command/add.rs:1827`）在 `!args.refresh && !args.update && !args.ignore_missing && !args.renormalize && !args.sparse` 时传 `true`（`add --refresh` `:1860`、`add --renormalize` `:139, :1805`、`add --sparse` `:164`、`add -N` `:1558`、`add -p` `:1189` 及 `run_add_resolved` `:1371-1397` 等 Out-of-scope 调用方均保持 `false`）。`run_add` 只调用一次 `env::current_dir()`，把这个绝对路径交给新增的 `util::try_resolve_invocation(cwd)`（`src/utils/util.rs`，基于私有 `try_get_paths_full` `BranchStoreError::Corrupt`，不得当成 unborn。存储/DB 错误 fail-closed。同时在普通 `add`（`run_add`，`src/command/add.rs:1667`）完成校验后，若处于 `unborn && empty_index`、允许放行模式、待暂存文件与诊断集合均为空，且 pathspec 集合为空或每个 spec 都是 `is_plain_repo_root_positive`，则在 `save_index`（`src/command/add.rs:2229`）前直接返回。`has_positive()==false` 且集合非空的 exclude-only 不走这条提前返回，继续执行到 `save_index` 并退出 0 `Ok(AddOutput::empty(args.dry_run))`（同 `:1726` 现有 no-op 返回类型）作为真正 no-op（不创建/改写 `.libra/index`）。错误码/文案不变。
- **Alternatives considered:** 新增「空仓库」专门提示（Git 静默，会引入噪声）。
- **Consequences:** `docs/error-codes.md` 无需改动。
- **Revisit when:** 需要区分空仓库诊断。

#!/usr/bin/env bash
# tests/command/add_empty_repo_gates.sh — one gate, one predicate.
set -euo pipefail
LIBRA="${LIBRA:-$PWD/target/debug/libra}"

index_digest() {
  local path="$1" line hash
  if test -L "$path" && ! test -e "$path"; then
    echo "index path is a broken symlink: $path" >&2
    return 1
  fi
  if test -e "$path"; then
    if ! line="$(shasum -a 256 "$path")"; then
      echo "sha256 failed for existing index: $path" >&2
      return 1
    fi
    hash="${line%% *}"
    if test -z "$hash" || test "$hash" = "$line"; then
      echo "sha256 output unusable for existing index: $path" >&2
      return 1
    fi
    printf '%s\n' "$hash"
    return 0
  fi
  printf 'absent\n'
}

capture_add() {
  local workdir="$1"
  shift
  rm -f "$root/out" "$root/err" "$root/rc"
  (
    cd "$workdir" || exit 97
    set +e
    "$LIBRA" add "$@" >"$root/out" 2>"$root/err"
    echo $? >"$root/rc"
  )
  if ! test -s "$root/rc"; then
    echo "add did not run in $workdir" >&2
    return 1
  fi
}

new_empty() {
  "$LIBRA" init "$1/e" >/dev/null
}

prepare_committed() {
  new_empty "$1"
  (
    cd "$1/e" || exit 97
    printf 'init\n' >init.txt
    "$LIBRA" add init.txt
    "$LIBRA" commit -m init >/dev/null
    "$LIBRA" rev-parse HEAD >/dev/null
  )
}

prepare_head_empty_index() {
  prepare_committed "$1"
  (
    cd "$1/e" || exit 97
    "$LIBRA" rm init.txt >/dev/null
    "$LIBRA" commit -m empty >/dev/null
    "$LIBRA" rev-parse HEAD >/dev/null
    listed="$("$LIBRA" ls-files)" || exit 1
    test -z "$listed"
  )
}

gate="${1:?gate name required}"
shift
root="$(mktemp -d)"
trap 'rm -rf "$root"' EXIT

case "$gate" in
  empty-rc|empty-stdout|empty-stderr|empty-index|empty-ls|empty-err-rc|empty-err-code)
    new_empty "$root"
    if test "$gate" = empty-index; then
      before="$(index_digest "$root/e/.libra/index")" || exit 1
    fi
    capture_add "$root/e" "$@"
    case "$gate" in
      empty-rc) test "$(cat "$root/rc")" -eq 0 ;;
      empty-stdout) test ! -s "$root/out" ;;
      empty-stderr) test ! -s "$root/err" ;;
      empty-index)
        after="$(index_digest "$root/e/.libra/index")" || exit 1
        test "$before" = "$after"
        ;;
      empty-ls)
        listed="$(cd "$root/e" && "$LIBRA" ls-files)" || exit 1
        test -z "$listed"
        ;;
      empty-err-rc) test "$(cat "$root/rc")" -ne 0 ;;
      empty-err-code) grep -q 'LBR-CLI-003' "$root/err" ;;
    esac
    ;;
  empty-err-lit)
    lit="${1:?literal required}"
    shift
    if test "${1:-}" != "--"; then
      echo "empty-err-lit requires -- before add args" >&2
      exit 2
    fi
    shift
    new_empty "$root"
    capture_add "$root/e" "$@"
    grep -q -F -- "$lit" "$root/err"
    ;;
  subdir-dot-rc|subdir-dot-code)
    new_empty "$root"
    mkdir -p "$root/e/sub"
    capture_add "$root/e/sub" .
    case "$gate" in
      subdir-dot-rc) test "$(cat "$root/rc")" -ne 0 ;;
      subdir-dot-code) grep -q 'LBR-CLI-003' "$root/err" ;;
    esac
    ;;
  subdir-parent-rc|subdir-parent-stdout|subdir-parent-stderr|subdir-parent-index|subdir-parent-ls)
    new_empty "$root"
    mkdir -p "$root/e/sub"
    if test "$gate" = subdir-parent-index; then
      before="$(index_digest "$root/e/.libra/index")" || exit 1
    fi
    capture_add "$root/e/sub" ..
    case "$gate" in
      subdir-parent-rc) test "$(cat "$root/rc")" -eq 0 ;;
      subdir-parent-stdout) test ! -s "$root/out" ;;
      subdir-parent-stderr) test ! -s "$root/err" ;;
      subdir-parent-index)
        after="$(index_digest "$root/e/.libra/index")" || exit 1
        test "$before" = "$after"
        ;;
      subdir-parent-ls)
        listed="$(cd "$root/e/sub" && "$LIBRA" ls-files)" || exit 1
        test -z "$listed"
        ;;
    esac
    ;;
  nonempty-err-rc|nonempty-err-code)
    prepare_committed "$root"
    capture_add "$root/e" nonexistent
    case "$gate" in
      nonempty-err-rc) test "$(cat "$root/rc")" -ne 0 ;;
      nonempty-err-code) grep -q 'LBR-CLI-003' "$root/err" ;;
    esac
    ;;
  nonempty-add-rc)
    prepare_committed "$root"
    printf 'x\n' >"$root/e/f"
    capture_add "$root/e" -A .
    test "$(cat "$root/rc")" -eq 0
    ;;
  nonempty-add-staged)
    prepare_committed "$root"
    printf 'x\n' >"$root/e/f"
    capture_add "$root/e" -A .
    listed="$(cd "$root/e" && "$LIBRA" ls-files)" || exit 1
    printf '%s\n' "$listed" | grep -qx 'f'
    ;;
  add-n-rc|add-n-code)
    new_empty "$root"
    capture_add "$root/e" -N .
    case "$gate" in
      add-n-rc) test "$(cat "$root/rc")" -ne 0 ;;
      add-n-code) grep -q 'LBR-CLI-003' "$root/err" ;;
    esac
    ;;
  head-empty-rc|head-empty-code)
    prepare_head_empty_index "$root"
    capture_add "$root/e" .
    case "$gate" in
      head-empty-rc) test "$(cat "$root/rc")" -ne 0 ;;
      head-empty-code) grep -q 'LBR-CLI-003' "$root/err" ;;
    esac
    ;;
  refresh-rc|refresh-code)
    new_empty "$root"
    capture_add "$root/e" --refresh .
    case "$gate" in
      refresh-rc) test "$(cat "$root/rc")" -ne 0 ;;
      refresh-code) grep -q 'LBR-CLI-003' "$root/err" ;;
    esac
    ;;
  renormalize-rc|renormalize-code)
    new_empty "$root"
    capture_add "$root/e" --renormalize .
    case "$gate" in
      renormalize-rc) test "$(cat "$root/rc")" -ne 0 ;;
      renormalize-code) grep -q 'LBR-CLI-003' "$root/err" ;;
    esac
    ;;
  sparse-rc|sparse-code)
    new_empty "$root"
    capture_add "$root/e" --sparse .
    case "$gate" in
      sparse-rc) test "$(cat "$root/rc")" -ne 0 ;;
      sparse-code) grep -q 'LBR-CLI-003' "$root/err" ;;
    esac
    ;;
  update-rc)
    new_empty "$root"
    capture_add "$root/e" --update .
    test "$(cat "$root/rc")" -ne 0
    ;;
  ignore-missing-rc)
    new_empty "$root"
    capture_add "$root/e" --dry-run --ignore-missing .
    test "$(cat "$root/rc")" -ne 0
    ;;
  magic-rc)
    spec="${1:?magic pathspec required}"
    new_empty "$root"
    capture_add "$root/e" "$spec"
    test "$(cat "$root/rc")" -ne 0
    ;;
  exclude-only-rc)
    new_empty "$root"
    capture_add "$root/e" ':(exclude).'
    test "$(cat "$root/rc")" -eq 0
    ;;
  exclude-only-index)
    new_empty "$root"
    before="$(index_digest "$root/e/.libra/index")" || exit 1
    test "$before" = absent
    capture_add "$root/e" ':(exclude).'
    after="$(index_digest "$root/e/.libra/index")" || exit 1
    test "$after" != absent
    test "$before" != "$after"
    ;;
  all)
    test -n "${LIBRA:-}" && test -x "$LIBRA" || { echo "LIBRA must be the binary from cargo build --bin libra" >&2; exit 1; }
    fail=0
    run_gate() { bash -euo pipefail "$0" "$@" || fail=1; }
    run_gate empty-rc -A .
    run_gate empty-stdout -A .
    run_gate empty-stderr -A .
    run_gate empty-index -A .
    run_gate empty-ls -A .
    run_gate empty-rc -A -- .
    run_gate empty-stdout -A -- .
    run_gate empty-stderr -A -- .
    run_gate empty-index -A -- .
    run_gate empty-ls -A -- .
    run_gate empty-rc --all .
    run_gate empty-stdout --all .
    run_gate empty-stderr --all .
    run_gate empty-index --all .
    run_gate empty-ls --all .
    run_gate empty-rc .
    run_gate empty-stdout .
    run_gate empty-stderr .
    run_gate empty-index .
    run_gate empty-ls .
    run_gate empty-rc :/
    run_gate empty-stdout :/
    run_gate empty-stderr :/
    run_gate empty-index :/
    run_gate empty-ls :/
    run_gate empty-rc -A
    run_gate empty-stdout -A
    run_gate empty-stderr -A
    run_gate empty-index -A
    run_gate empty-ls -A
    run_gate subdir-parent-rc
    run_gate subdir-parent-stdout
    run_gate subdir-parent-stderr
    run_gate subdir-parent-index
    run_gate subdir-parent-ls
    run_gate empty-err-rc nonexistent
    run_gate empty-err-code nonexistent
    run_gate empty-err-lit nonexistent -- nonexistent
    run_gate empty-err-rc . nonexistent
    run_gate empty-err-code . nonexistent
    run_gate empty-err-lit nonexistent -- . nonexistent
    run_gate empty-err-rc :/ nonexistent

    run_gate nonempty-err-rc
    run_gate nonempty-err-code
    run_gate nonempty-add-rc
    run_gate nonempty-add-staged
    run_gate add-n-rc
