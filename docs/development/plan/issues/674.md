## 文档职责

### 适用范围

**适用范围：** `libra repack -A/-Ad` 的参数、旧 pack 中不可达对象 loose 化、删除顺序/故障安全、delta-chain 回归、repack EN/zh/开发/兼容/网站文档，以及 TC-0129 后置复核。**非目标：** 实现全局 `-c`（由 `issues/557.md#CO-17` 交付）、新增 `.git` shim、修改 testcase 仓、改变 `-a/-ad`、archive/verify-pack 或 pack 编码器的其它语义。**成功定义：** `-A` 与 Git 对齐；`-Ad` 在删除旧 pack 前持久化其不可达对象为 loose；既有 `-ad` 不回归；链长判据成立；#557 与 D-layout 门满足后 TC-0129 原样 PASS；否则如实保留未完成状态。

### 成功定义

## 已决议设计决策

### ADR-674-01：`-A` 是独立模式标志
- **Status:** Accepted；**Context:** Git 的 `-A` 无 `-d` 时等同 `-a`，有 `-d` 时才 loose 化旧 pack 的不可达对象；**Decision:** 新增 `-A` 字段并令 packing set 等同 `-a`，仅删除阶段分叉；**Alternatives:** 把 `-A` 做 `-a` alias（丢失关键语义）或改写 `-a`（回归）；**Consequences:** 公开 CLI/文档更新；**Revisit when:** Git 改变 repack 合同。

### ADR-674-02：持久化后删除，任一失败保留旧 pack
- **Status:** Accepted；**Context:** 当前覆盖判定只会保留含 unreachable 的 pack；**Decision:** 在 exclusive hold 下枚举候选旧 idx，把 `reachable` 外对象逐个解码、OID/type 校验并原子写 loose，确认文件与父目录 durable 后才删 `.pack/.idx`；`.keep` 与 borrower 门继续优先；**Alternatives:** 先删后写或整包驻内存（数据丢失/容量风险）；**Consequences:** 崩溃可留下安全重复副本；**Revisit when:** 对象库获得跨 pack/loose 事务。

### ADR-674-03：产品修复与原样 TC 结论分离
- **Status:** Accepted；**Context:** TC-0129 还受 #557 与硬编码 `.git/objects/pack` 约束；**Decision:** I674-01 独立发布，A674-02 只在 `issues/557.md#CO-17` 完成且 D-layout 个案有具名结论后运行原脚本；SKIP 不冒充 Issue 的 PASS；**Alternatives:** 加 `.git` shim/改上游脚本（违反现行政策）；**Consequences:** 产品修复可先交付，Issue 关闭可能后置；**Revisit when:** D-layout 政策或仓库布局改变。
