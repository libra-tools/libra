## 文档职责

### 适用范围

`libra branch -v --list t` 的只读 exact selector，以及 human verbose 列表的 `--abbrev[=<n>]`、`--no-abbrev`、`core.abbrev` 对象 ID 宽度；同卡覆盖 Rust 回归、TC-0156、EN/zh-CN/开发/兼容/网站文档与独立 patch 发布。

### 非目标

不实现 glob/多 pattern/`--ignore-case` pattern 语义，不实现跨命令唯一前缀 `core.abbrev=auto`，不修 t3200 orphan cleanup（由 `issues/676.md#I676-01` 承接），不实现 T 类 `commit-graph`，不修改 testcase 仓库，也不改变 JSON/machine 的完整 OID 合同。

### 成功定义

六种上游命令均被接受并产生 Git 兼容宽度；四个前缀/长度断言与 TC-0156 通过；无 `--list` 的位置参数仍是创建动作；配置/参数失败在输出前 fail-closed；文档、网站、patch release 与 D 组证据闭合后方可完成。
