## 远端交付与保护（main 直推口径）

`main` 没有分支保护，直推本身不构成远端代码审查。允许临时 `review/I677-01` 与对应 PR，只为取得一条 `state=APPROVED` 且 reviewer 不是推送者的审查，以及同一已签名 SHA 的 `pull_request` `base.yml` 与 `codeql.yml` success。`required_status_checks` 与 PR 结论都不能代替那条审查。通过后，仅当 `origin/main` 仍等于提交父时，执行不带 `--force` 的 `libra push origin main`，把同一 SHA 快进到 `main`。禁止 squash 与 force。若 `main` 已前进，停止并按 ER-09 重取。本地 diff 只含卡内写集、本计划、`plan-status.md`、ER-08 版本面和 lock；同一提交有 PGP 与 DCO。推后远端等于本卡 SHA，再以该 SHA 创建一致 `v*` Release。`Acceptance=complete` 仍要等下面 D 组里本 SHA 的 `main` push 与 Release 实际 success。
