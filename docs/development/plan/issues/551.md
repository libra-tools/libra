## 已决议设计决策

### ADR-SC-01：enum 外识别

**Status:** Accepted。`src/cli.rs:3080-3115` 的未知顶层命令分支内集中精确匹配有意拒绝的名称，命中时按既有 `CliError::failure(...).with_stable_code(StableErrorCode::Unsupported)` 构造；不得误识参数值、非顶层 token 或其它命令。`Commands`、根 Command Groups 与主兼容表不增加 variant。未来需要实际支持时重新评估 variant、主表迁移和 `compat_help_examples_banner`、`cli::tests::root_after_help_lists_every_visible_command`、`compat_command_docs_examples_section` 三守卫（DEFER-SC-04，T-1）。

### ADR-SC-02：稳定诊断与有限替代

**Status:** Accepted。主消息说明 D10 和不物化；最多两条普通 hint（`with_hint` 上限两条）指向以下可执行例子及文档。不得使用显式退出码 override 绕过 fine 模式；文档按真正的发布版本记载旧默认 129/fine 2 到新默认 128/fine 8 的变化。

```sh
# 在已有 Libra 仓库中，保存并启用视图配置；仅过滤展示，不物化工作树
libra sparse-view set 'src/**' 'docs/**'
libra ls-files
libra diff
# 另一个有限工具：下面的路径必须已经在 index 中
libra update-index --skip-worktree tracked-file.txt
libra add --sparse tracked-file.txt  # 显式暂存该已修改且存在的文件
```

`skip-worktree` 不读取或物化工作树；未跟踪路径会报错。`sparse-view set` 会通过 `SparseViewStore::replace` 保存并启用视图配置，但只过滤 `ls-files`/`diff` 的展示，不修改工作树文件或 skip-worktree 位，并非 Git 稀疏检出。不能承诺这些有限工具提供完整 Git 等价行为。拒绝保留误导性的 `a similar subcommand exists`；`send-email` 诊断统一不在本卡。

### ADR-SC-03：上游结果的事实优先

**Status:** Accepted。28 项在 `0.30.91` 中是带 T 注记的 FAIL；本卡只改变拒绝诊断，不实现阻断能力，因此预期仍有 T 失败，但这不是对未来结果的断言。T 类真实 FAIL 仍为 FAIL；真实 PASS/PASS-XFAIL 原样保留、调查环境、其它修复和归因，必要时先修订计划并重审。若混有 D 依赖，按上游政策对符合条件的 D 类 FAIL 记 SKIP 并保留原始 FAIL 和更早 T blocker；不能改变真实通过。TC-0034 的四项「实现之后」验收未由本卡完成。

## 全局工程约束

继承 GC-01..GC-13；数据库角色 N/A，不改 schema、连接或迁移。拒绝发生于顶层解析失败路径，不得新建持久状态。测试把 `HOME`、`XDG_CONFIG_HOME`、`LIBRA_HOME`、global/system config DB 均指向隔离目录，清除日志输出与 fine 环境变量后分别设置模式；仓库 fixture 前后递归快照路径、文件类型/权限、symlink 目标、文件内容 hash，包括 index、objects、SQLite 主库及 WAL/SHM、配置和工作树。非仓库 fixture 同样比较；输出与快照放内存，不得混入被比较目录。为排除测试自身噪声，构造完成并关闭 SQLite 后基线快照，调用完成后再快照；失败即整门失败。

**no-JUnit 与重跑安全：** 每轮验收开始前，在已有的、操作者拥有的仓外 scratch 根创建新的私有临时目录；不得接受输出文件路径作为输入，不覆盖已有文件。下列块在 Libra 仓库根执行；`SCRATCH_ROOT` 必须预先指向已有绝对目录。解析物理路径后同时排除 Libra、backend 和 testcase checkout 的根及其后代。目录只供本轮临时配置，不是证据目录；不设置 `CARGO_TARGET_DIR`，正常 Rust 编译缓存可复用；若某测试需不存在的目标目录，使用该轮私有目录下的新子路径，重跑重新申请目录，不删除他人内容。

```bash
set -euo pipefail
: "${SCRATCH_ROOT:?set an existing external scratch root}"
case "$SCRATCH_ROOT" in /*) ;; *) exit 1;; esac
SROOT="$(cd -P -- "$SCRATCH_ROOT" && pwd -P)"
test -d "$SROOT" && test -O "$SROOT"
for repo in /mnt/data/gitmono/libra /mnt/data/gitmono/libra-backend /mnt/data/gitmono/libra-testcases; do
  ROOT="$(cd -P -- "$repo" && pwd -P)"
  case "$SROOT/" in "$ROOT/"*) exit 1;; esac
done
RUN_DIR="$(umask 077; mktemp -d "$SROOT/libra-sc-nextest.XXXXXXXX")"
test -O "$RUN_DIR" && test ! -L "$RUN_DIR"
NEXTEST_NOJUNIT_CFG="$RUN_DIR/nextest.toml"
(set -C; python3 -I -c 'import sys; p=sys.argv[1]; s=open(p,encoding="utf-8").read().splitlines(keepends=True); a="[profile.default.junit]\n"; b="path = \"junit.xml\"\n"; assert s.count(a)==s.count(b)==1; sys.stdout.writelines(x for x in s if x not in (a,b))' .config/nextest.toml > "$NEXTEST_NOJUNIT_CFG")
test -f "$NEXTEST_NOJUNIT_CFG" && test ! -L "$NEXTEST_NOJUNIT_CFG"
```

同一轮的 nextest 命令可复用该配置；重跑另建私有目录并在同一 shell 使用新路径。内容形态变化即停止修计划，不能用不带配置的 nextest。v2.12 禁止新建证据文件/目录，不禁止执行上游测试；本计划选择只读公开结果是范围决定。临时 fixture/配置不是证据归档，摘要、结果、SHA 和 run ID 写入本计划。不得保存私有路径、密钥或原始隐私数据。

- `policy_review`、`investigation_review`、`reply_review` 均写 `reviewer=<姓名>;utc=<秒级UTC>`，由实际复核者完成。复核者必须逐行打开固定政策、原始行、调查依据和拟回复后才签名，空泛的“已检查”不算调查。
- `fix_dep` 为 `none` 或实际登记的 FIX/DEP ID；对应 `resolution` 只能是 `resolved` / `unresolved`。任何 `unresolved` 或 `change_class=undisclosed` 都令 V10 blocked；脚本仍继续执行 V11..V15，最后统一非零退出。
- 拟回复块以 `SOURCE_VERSION=<RESULT_VERSION>`、`SOURCE_SHA=<RESULT_SHA>` 开头，每个 TC 恰有一个 `### TC-xxxx` 小节，并原样包含该行 `reply_attribution`。未披露和 unresolved 必须在相应小节明确出现。
