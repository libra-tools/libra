# Issue #979：`--pretty=format:` 不得附加终止换行（`%b` 在无正文提交上必须是 0 字节）（2026-11-12）

> 模板 v2.16。[Issue #979](https://github.com/libra-tools/libra/issues/979) OPEN。仅规划，未授权执行；`I979-01` 为 `pending` / Acceptance 空。Git 对照 pin `6de20f6092dcf9bdb1c8efe03db4b70c82b423dd`。基线 `Cargo.toml` `0.30.173`（`Cargo.toml:3`）；实测 system `libra 0.30.173`。测试用例仓 `/mnt/gitmono/libra-testcases` 本计划不修改。

## 文档职责

### 适用范围

`show`/`log` 的 `--pretty=format:<tmpl>` 与 `--format=<tmpl>` 的终止换行语义：`format:` **不**附加终止换行（单提交时无尾随换行，`log` 多提交时仅在条目之间插入分隔换行），`tformat:` 对每个提交附加终止换行。覆盖 `show` 的自定义格式输出路径、`log` 的自定义格式输出路径，以及 `parse_pretty_format` 对 `format:`/`tformat:` 前缀的区分保留；并确保 `%b` 在无正文提交上产生 0 字节。

### 非目标

不改 `oneline`/`medium`/`short`/`full`/`fuller`/`reference`/`raw` 七个预设的既有输出；不改 `%b`/`%B` 的内容语义（正文是否含内部空行、是否去尾随空行）；不改 `--pretty` 与 `--format` 的互斥与别名关系；不改 `configured_pretty()` 配置回落；不改 `--notes`/`--name-only`/`--stat`/`-p` 的追加块顺序；不改 `merge` 的消息标题（`issues/974.md`）；不修改测试用例仓。

### 成功定义

- `libra show -s --pretty=format:%b HEAD` 在无正文提交上 stdout 恰为 0 字节。
- `libra show -s --pretty=format:%s HEAD` 输出主题行且**无**尾随换行。
- `libra show -s --pretty=tformat:%s HEAD` 输出主题行**带**一个尾随换行。
- `libra log --pretty=format:%s` 在多提交时条目间仅一个换行、最后一条之后无换行；`--pretty=tformat:%s` 每条之后都有换行。
- 有正文提交的 `%b` 仍以恰一个换行结束（正文语义不变）。
- 七个预设与 `show` 默认输出逐字节不变。

## 已决议设计决策

### ADR-I979-01：`FormatType::Custom` 携带终止符语义

- **Status:** Accepted
- **Context:** `parse_pretty_format`（`src/command/log.rs:2872-2889`）把 `format:` 与 `tformat:` 都折叠为 `FormatType::Custom(String)`，两个前缀的可观察差异（终止换行）无处表达。
- **Decision:** 把该变体扩为 `Custom { template: String, terminator: Terminator }`，`Terminator::{ None, Newline }`：`format:` → `None`，`tformat:` → `Newline`，无前缀的裸模板沿用 Git 的 `tformat:` 行为 → `Newline`。
- **Alternatives considered:** 在 `show`/`log` 打印处按原始字符串再判前缀（会与 `parse_pretty_format` 重复解析，且两处易漂移）。
- **Consequences:** 终止符成为解析产物；渲染调用点只读枚举。
- **Revisit when:** Git 增加第三种终止语义。

### ADR-I979-02：终止符由单一调用点追加，禁止打印处二次补换行

- **Status:** Accepted
- **Context:** `src/command/show.rs:1034-1035` 无条件 `push('\n')`；`src/command/log.rs:2413-2430` 在自定义格式后继续追加 notes/路径/补丁块。
- **Decision:** 由 `CommitFormatter` 的调用方在拿到 `formatter.format(...)` 结果后，**只**依据 `Terminator` 决定是否追加一个 `\n`；`show` 的自定义格式分支不再无条件补换行。`log` 的多提交分隔：`None` 时条目之间插入一个 `\n`（最后一条不插），`Newline` 时每条自带终止换行。
- **Alternatives considered:** 让 `format_custom` 自己加终止符（会污染 `%b`/`%B` 内部取值与既有单测）。
- **Consequences:** `%b` 内部值保持纯净；终止符可单点测试。
- **Revisit when:** N/A。

### ADR-I979-03：正文渲染保持不变，只改终止符

- **Status:** Accepted
- **Context:** `pretty_message_body`（`src/internal/log/formatter.rs:560-565`）在无正文时返回 `""`；有正文时经 `ensure_trailing_newline` 得到一个尾随换行。
- **Decision:** 不改 `pretty_message_body`/`pretty_raw_body`。`%b` 在无正文提交上为 `""`，加上 `Terminator::None` 后 stdout 恰 0 字节；有正文时仍以恰一个换行结束。
- **Alternatives considered:** 在 `%b` 分支里剥掉换行（会破坏 `%b` 与 `%B` 的既定差别）。
- **Consequences:** 1 字节差异只在终止符层面修正。
- **Revisit when:** N/A。
