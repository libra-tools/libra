## 文档职责

处理 #553 所列当前仍成立的 `--start-after`、`%(contents:lines=N)` 和重复 `%(then)`；对上游夹具依赖的任意 ref 命名空间单独登记阻塞，不把其它命令的未实现能力假装为本计划已覆盖。历史版本的失败数量不是当前通过率。

### 适用范围

在现有可枚举 refs 上实现游标分页、内容行数原子、条件格式语法验证；同卡测试、帮助、命令双语、网站、开发文档和兼容矩阵。上游 t6302 对应案例执行并按实际结果记账。

### 非目标

不实现通用 `update-ref` 或任意命名空间存储；不扩展与 issue 无关的其它 atom/排序；详见延后表。完整上游测试可能先被 `refs/odd/*` 建立或枚举阻塞，因此计划完成不自动等于 issue 可关闭。

### 成功定义

活动卡各自形成可验收的用户行为切片；固定 Git 对照下目标场景输出及退出状态一致，冲突选项在输出之前拒绝；每个上游用例逐例记实，受阻不能记为通过。

执行 nextest 前在仓库根的当前 shell 定义以下函数。它逐次复制现行生成配置，仅移除默认 JUnit 输出段并保留所有 test-group/override，锁定 default profile 并拒绝 profile 覆盖；临时文件是仓外配置输入，退出即删除，不是证据文件。源配置结构改变或校验失败就停止并修订计划；所有 nextest 命令均通过它运行，等价保留原测试选择和重试语义。

```bash
libra_plan_nextest() (
  set -e
  LIBRA_PLAN_MODE=run
  if [ "${1:-}" = run ] || [ "${1:-}" = list ]; then LIBRA_PLAN_MODE=$1; shift; fi
  for LIBRA_PLAN_ARG in "$@"; do
    case "$LIBRA_PLAN_ARG" in -P|--profile|--profile=*|-P?*) printf '%s\n' 'profile override refused' >&2; exit 1;; esac
  done
  python3 -I -c 'import pathlib; p=pathlib.Path("/tmp").resolve(strict=True); root=pathlib.Path.cwd().resolve(); assert p!=root and root not in p.parents'
  LIBRA_PLAN_RUN_DIR="$(mktemp -d /tmp/libra-plan-553.XXXXXXXX)"
  case "$LIBRA_PLAN_RUN_DIR" in /tmp/libra-plan-553.*) ;; *) exit 1;; esac
  trap 'rm -rf -- "$LIBRA_PLAN_RUN_DIR"' EXIT
  python3 -I -c 'import os,pathlib,sys; r=pathlib.Path(sys.argv[1]).resolve(strict=True); root=pathlib.Path.cwd().resolve(); assert r.parent==pathlib.Path("/tmp").resolve() and root!=r and root not in r.parents; os.chmod(r,0o700); s=pathlib.Path(".config/nextest.toml").read_text(); b="[profile.default.junit]\npath = \"junit.xml\"\n"; assert s.count(b)==1; (r/"nextest.toml").open("x").write(s.replace(b,"",1))' "$LIBRA_PLAN_RUN_DIR"
  cargo nextest "$LIBRA_PLAN_MODE" --config-file "$LIBRA_PLAN_RUN_DIR/nextest.toml" --user-config-file none --profile default "$@"
)
```
