## 已决议设计决策

### ADR-I1051-01: stdin 先于位置路径

删除 `--stdin` 与 `paths` 的冲突。两条输出路径（文本与 JSON）都在 `--stdin` 时先发标准输入的一个对象，再按 `paths` 顺序发文件。`--stdin-paths` 继续同时拒绝 `--stdin`、位置路径和 `--path`。`--path` 仍只标注标准输入对象，不作用于位置文件。`--no-filters` 与 `--path` 的现有冲突保持。读文件失败时不得先写出已计算的后续行；标准输入已哈希但文件读取失败时进程以非零退出，测试覆盖该失败不再把退出码 0 当成功。
