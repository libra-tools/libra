## 已决议设计决策

### ADR-I1056-01: 新函数过滤前缀

新增 `write_tree_from_index_prefix(index, prefix, missing_ok)`。前缀按 Git 选项原样使用，调用方传入的字符串必须带尾部 `/`；没有尾部 `/` 时命令退出 129 并提示形式 `--prefix=<dir>/`，不写对象。函数只保留路径以该前缀开头的 stage-0、非 intent-to-add 条目，写树前去掉这段前缀。没有任何匹配条目时返回可映射为退出 128 的错误，stderr 含 `prefix <原样前缀> not found`，不写树对象。`--missing-ok` 只作用于筛出的 blob，语义与无前缀阀门相同。根索引的 `write-tree` 不带该选项时字节行为不变。
