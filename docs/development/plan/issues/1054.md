## 已决议设计决策

### ADR-I1054-01: 去掉隐式 HEAD

无 spec、无 `--default`、无查询模式、无 `--verify`/`--short` 时，结果列表为空。文本模式不输出，退出 0。`--json` 沿用现有多 spec 分支，发出空数组，不新增信封。查询模式仍合成一次占位并打印原来的一个值。`--verify` 或 `--short` 且 spec 数不是 1 时保持 `Needed a single revision`（退出 128），不得再偷偷解析 HEAD。`--default <arg>` 与 `rev-parse -- <path>` 的现有分支不改。
