## 文档职责

本文把 `plan-20260715.md` 完成判据勾选之后**仍然未实现**的能力收成可执行任务卡。2026-08-24 源码核对结论：W0–W6 与 WIO-01..03 共 71 张卡已落地，`libra code` 默认 Web Code UI，`AgentRuntimeWorker` 是唯一状态机 owner，Code TUI / `code-control` / `--web` 别名已随 v0.20.0 breaking minor 删除。未实现部分是计划明文延期的 DEFER 项，以及一条已文档化的 fail-closed 残差（skill activate）。

本文只规划任务，不宣称实现完成。落地时每个任务都必须先刷新源码锚点，再按任务卡验收。**禁止重开已关闭的 W0–W6 / WIO 卡。**

### 适用范围

- `review --fix` / `investigate fix` 的 AgentRuntime serialized mutating bridge（0715 DEFER-01；0714 PD-01 的可执行拆分）。
- SSE wire 默认切到 v2，以及满足 DEFER-08 清单后的 v1 snapshot stream 物理移除。
- `test_create_tree` object-index repair-marker 共享锁隔离（0715 DEFER-10）。
- Code UI `POST /api/code/skills/activate` 从 discoverability-only 升级为 provider 可消费的激活效果。
- 事实源刷新：`tracing/code.md` C10 过期缺口、`plan-20260714.md` PD-01 过期 BLOCKED 句、`plan-20260715.md` DEFER-09 关闭、`plan-long.md` 日期计划索引。

### 非目标

- 不重做 `plan-20260715` 已关闭的 W 卡、不恢复 Code TUI、不重写 `AgentRuntimeWorker`。
- 不在 Code 路径复制第二套 mutation queue / approval / sandbox（ADR-DF-02）。
- 不实现独立 `libra mcp --stdio`（DEFER-02）、MCP 授权门闭环（DEFER-03）、非 loopback 远程写面（DEFER-04）、单短横 `-control`（DEFER-05，永久不做）。
- 不等待、不伪造 Codex app-server 的完整 user-input 纳管（DEFER-07）。
- 不实现浏览器内 in-process AgentRuntime session 热切换（`SESSION_RESUME_REQUIRES_RESTART` 保留；CLI `--resume` 已工作）。
- 不实现 0714 PD-02 scoped review、PD-03 cloud tombstone 等非 0715 DEFER 范围。

### 成功定义

- `libra review --fix` 与 `libra investigate fix` 在 runtime 可用时进入 serialized mutating workflow；无 runtime / 无权限时仍 `LBR-AGENT-010`；untrusted seed 先触发 `LBR-AGENT-011`。
- 省略 `wire` 的 `GET /api/code/events` 默认为 v2；显式 v1 在烘焙窗口内仍可用；窗口满足后 v1 分支删除。
- 满载 `cargo test --all` 不再因 `command::commit::test::test_create_tree` 的共享锁超时失败。
- discoverable skill 的 `POST /api/code/skills/activate` 产生 provider 可消费的激活效果，不再固定 `SKILL_ACTIVATION_UNSUPPORTED`。
- 所有非延后任务 `Lifecycle=done` 且 `Acceptance=complete`；计划完成门全绿。

## 已决议设计决策

### ADR-DF-01: 不重开 plan-20260715 已关闭任务卡

- **Status:** Accepted
- **Context:** 0715 Checkpoint A–D 与完成判据已勾选；源码已是 Web-default + runtime owner。
- **Decision:** 本计划只新增 `DF-*` 卡。发现 0715 卡面与代码不一致时，修文档或另立 `FIX-*`，不得把已关闭 W 卡改回 pending。
- **Alternatives considered:** 在 0715 上追加卡——与「计划完成」矛盾，且模板增量迁移会把 71 张旧卡拖进 v2.1。
- **Consequences:** 0715 保持历史完成态；本文件是唯一开工事实源。
- **Revisit when:** 发现 0715 主线功能实际回归。

### ADR-DF-02: mutating fix 只走既有 AgentRuntime 入口

- **Status:** Accepted
- **Context:** 0715 ADR-CODE-04 / F37：A0-05 bridge 依赖 runtime，禁止第二套 queue。
- **Decision:** DF-03/DF-04 经 `AgentRuntimeHandle::submit`（或与 `submit_confirmed_plan_execution` 同级的 typed mutating 入口）+ `runtime::hardening` + 既有 approval/sandbox/ACL。无 runtime 时仍 `LBR-AGENT-010`。
- **Alternatives considered:** review CLI 直接调 tool loop——绕过串行化与 lease。
- **Consequences:** 共享 `src/internal/ai/runtime/` 写集，`DF-03 -> DF-09 -> DF-04` 串行。
- **Revisit when:** runtime 入口重构。

### ADR-DF-03: SSE v1 删除必须满足 DEFER-08 五条清单

- **Status:** Accepted
- **Context:** 0715 ADR-CODE-08：v2 成为默认后再保留 ≥1 个成功公开 patch。
- **Decision:** DF-05 迁 automation/compat；DF-06 切服务端默认；DEP-02 登记烘焙；DF-08 才删 v1。禁止 DF-06 与 DF-08 合并发布。
- **Alternatives considered:** 直接删 v1——破坏未升级的 automation。
- **Consequences:** DF-08 在烘焙完成前保持 `blocked`。
- **Revisit when:** 清单第 2 条（automation 已迁）被证伪。

### ADR-DF-04: in-process session 热切换本计划不做

- **Status:** Accepted
- **Context:** `POST /api/code/session/resume` 已能证明 thread 可加载，但热替换 live worker/lease/durability 是独立行为轴。
- **Decision:** 保留 `SESSION_RESUME_REQUIRES_RESTART`；用户路径仍是 `libra code --resume`。登记 DEFER-DF-01。
- **Alternatives considered:** 本计划做热切换——会与 lease/W1-05 indeterminate 缠在一起，超出 focused session。
- **Consequences:** Web 线程列表切换需重启进程。
- **Revisit when:** 独立设计通过 Claude/Codex review。
