- adapt：只取经指出的算法、事务模式或测试场景，按新契约重写；不代表复制整个模块。

## 必须显式改写的语义，不能“搬完再修”

1. **代码路径与逻辑路径不同。** query.rs:146 的点分 path 校验和 applicability.rs:274 的控制字符/反斜杠禁令不适用。新路径契约需要落实原字节存储、精确参数绑定、JSON 表达与人读 C-style quoting。仅用 String / to_string_lossy 不能声称支持非 UTF-8 文件名。
2. **漂移不是可注入性。** 旧 Exact/DescendantUnchanged/DescendantPathChanged/Diverged/Unknown 和 injectable 过滤不等于新三态 drift；changed/path-gone 历史也必须可召回。缺失/损坏对象、NULL anchor 与真实 path-gone 必须区分，不猜测。
3. **replace 必须使用同一冻结映射。** 旧 applicability.rs 直接从 LocalStorage 解析原始 commit/tree；若新 fingerprint 包含 replace signature，则派生与 drift 必须使用相同 pinned replace snapshot，不能“指纹用有效历史、读取用原始历史”。
4. **集合可撤销。** 旧 ref/event-sequence 水位不能检测 session resume 或相同秒内重停；新规则还必须包含晚到 checkpoint、operation 原地状态变化、findings 的可解析性变化、出窗删除。增量结果必须与同一 horizon 的 rebuild 相同。
5. **FTS 词法不同。** 旧 normalize_plain_text_v1 按非字母数字拆词并 OR 连接，实际上会丢掉词内标点。DM-08 要求 phrase 字面量、双引号双写、运算符失效及 Unicode 空白对抗测试。只保留旧输入限额（4 KiB / 单词 256 B / 32 词）的思路，不保留其旧 golden 字符串。
6. **置信度不可偷换。** 旧 MemoryAnchorConfidence 是 low/medium/high 模型/锚置信度；新 link_confidence 是 identity/operation/temporal 证据关系。当前没有消费者需要前者，不应为了“取材”在 episode.rs 新建一个同义 MemoryConfidence。旧计划 DM-00 的该项表述应随迁移修订纠正。
7. **来源不能扩大。** 不索引 transcript、prompt、tool output；agent_session 不生产路径行，checkpoint.tree_oid 是 traces 树不是代码树；自然语言 investigate target_scope 不是路径。
8. **证据丢失不能删除有用记录。** 新 unresolved 边保留并标注；temporal 边永不当 citation。不能沿用旧 injectable/read-policy 过滤的结果作为新默认召回集合。
